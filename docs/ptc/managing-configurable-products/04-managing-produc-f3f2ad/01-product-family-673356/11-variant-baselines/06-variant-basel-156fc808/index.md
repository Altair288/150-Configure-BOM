<a id="wwID0EWADU"></a>

A variant baseline’s information page is accessible by clicking its view information icon in the [Variant Baselines](../05-variant-baselines-tab/index.md#wwID0EVWCU "Variant Baselines Tab")[ table](../05-variant-baselines-tab/index.md#wwID0EVWCU "Variant Baselines Tab").

<a id="wwID0EQBDU"></a>

## Tabs

<a id="wwID0EUBDU"></a>

Use the following tabs to view information and manage variant baselines.

| Tab | Description |
| --- | --- |
| **Details** | Contains object and system attributes related to the variant baseline. |
| **Variant Specifications** | Allows you to Manage which variant specifications and their revisions are associated with the variant baseline. For more information, see [Variant Specifications Table](../07-variant-specifi-d0d0bd/index.md#wwID0ENPDU "Variant Specifications Table"). |
| **Baseline Objects** | Displays parts that have been added to variant baseline. For more information, see [Baseline Objects Table](../08-baseline-objects-table/index.md#wwID0EXCEU "Baseline Objects Table"). |
| **History** | Displays maturity history for the variant baseline. For more information, see [History Information Tables](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/objectoview/ObjectOviewInfoTablesHistory.html). |

<a id="wwID0EBIDU"></a>

## Actions

<a id="wwID0EFIDU"></a>

Actions for managing variant baselines are available from the **Actions** menu. Some are common Windchill actions; for more information, see [Actions Common Among Objects](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/commonactions/CommonActionsRef.html). The following actions are particularly useful when working with variant baselines.

| Action | Description |
| --- | --- |
| **Update Variant Specifications** | Allows you to update a variant specification to the latest iteration of the revision being used in the variant baseline. This does not replace it with newer revision. For more information, see[Update Variant Specifications Window](../07-variant-specifi-d0d0bd/02-update-varian-cf4f7334/index.md#wwID0EA3DU "Update Variant Specifications Window"). |
| **Add Baseline Objects** ![](../../../../../images/5669a06a74e1_IconLotBaselineAdd.png) | Allows you to add parts to the variant baseline that are required to develop a prototype. For more information, see [Adding Baseline Objects](../08-baseline-objects-table/01-adding-baseline-1ccb9f/index.md#wwID0E11EU "Adding Baseline Objects"). |
| **Edit Baseline Objects** ![](../../../../../images/76994d3648f4_IconLotBaselineEdit.png) | Allows you to update the status and other soft attributes on the baseline member link as it progresses through the prototype development stages. For more information, see [Edit Baseline Objects Window](../08-baseline-objects-table/03-edit-baseline-o-9db595/index.md#wwID0ERZFU "Edit Baseline Objects Window"). |
