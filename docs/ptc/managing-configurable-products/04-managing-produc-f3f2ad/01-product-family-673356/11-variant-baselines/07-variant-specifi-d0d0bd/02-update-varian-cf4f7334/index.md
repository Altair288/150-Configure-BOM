# Update Variant Specifications Window

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodfamily/ProdFamilyUpdateProductVariantsWindow.html)  
> 获取日期：2026-11-12

<a id="wwID0EA3DU"></a>

<a id="wwID0ER3DU"></a>

Use the **Update Variant Specifications** window to update a variant specification revision.

<a id="wwID0E23DU"></a>

To open this window, from a variant baseline information page select Actions > Update Variant Specifications. The window opens and the following actions are available:

| Action | Description |
| --- | --- |
| **Add Variant Specifications** ![](../../../../../../images/b1709b767c8b_Add.jpg) | Opens the **Find Variant Specifications** window that allows you to search for variants by name, number, and revision to add them to the table. |
| **Remove Variant Specifications** ![](../../../../../../images/ae4a236e741a_IconRemove.gif) | Removes the variant specification from the **Variant Specifications** table. |

<a id="wwID0E23DU-4"></a>

Click **OK** after you have added, selected, or removed variant specifications from the **Variant Specifications** table. The window closes and your selections are updated in the **Variant Specifications** table.
