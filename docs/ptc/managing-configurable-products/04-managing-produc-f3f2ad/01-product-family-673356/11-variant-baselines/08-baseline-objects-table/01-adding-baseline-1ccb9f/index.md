# Adding Baseline Objects

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodfamily/ProdFamAddingBaselineObjects.html)  
> 获取日期：2026-11-12

<a id="wwID0E11EU"></a>

<a id="wwID0EL2EU"></a>

The variant baseline is used to organize components that are needed to build prototypes of variant specifications that are associated with the variant baseline. A baseline object’s status is tracked as it progresses through the prototype process. Baseline objects are added manually to variant baselines.

<a id="wwID0EQ2EU"></a>

To add baseline objects to a variant baseline, use the following procedure.

<a id="wwID0EJ3EU"></a>

1. Click the **Add Baseline Objects** ![](../../../../../../images/5669a06a74e1_IconLotBaselineAdd.png) action or icon.

<a id="wwID0EG4EU"></a>

1. The action is available from the following locations:

<a id="wwID0E64EU"></a>

- Right-click actions menu on a variant baseline object in the product family **Structure** tab and the **Variant Baselines** table on the product family **Variant Baselines** tab.

<a id="wwID0EN6EU"></a>

- Actions menu on the variant baseline information page.

<a id="wwID0EPAFU"></a>

- **Add Baseline Objects** ![](../../../../../../images/5669a06a74e1_IconLotBaselineAdd.png) icon on the **Baseline Objects** table tool bar on the variant baseline information page.

<a id="wwID0EACFU"></a>

- **Add Baseline Objects** ![](../../../../../../images/5669a06a74e1_IconLotBaselineAdd.png) icon on the **Baseline Objects** tab on the product family **Structure** tab.

<a id="wwID0EWDFU"></a>

2. The **Add Baseline Objects** window opens. Click **Add Part To Variant Baseline** ![](../../../../../../images/95a4c9475784_IconAdd.gif) icon.

<a id="wwID0EIFFU"></a>

3. The **Find Baseline Objects** window opens. Select a part object type and provide a name or number and then click **Search**.

<a id="wwID0EUGFU"></a>

4. Select parts from the **Search Results** table and click **OK**. The window closes and populates the **Baseline Objects** table in the **Add Baseline Objects** window with the selected objects.

<a id="wwID0EGIFU"></a>

5. Select parts from the **Baseline Objects** table. Optionally, for each part choose a revision and assign a status in the **Revision** and **Status** columns. Click **OK**. The window closes and populates the **Baseline Objects** table on the product family **Structure** tab and the variant baseline information page with your selections.

<a id="wwID0ERJFU"></a>

To edit attributes for more than one objects in the **Add Baseline Objects** window, use the following procedure:

<a id="wwID0EPKFU"></a>

1. Select the objects and click the**Edit Attribute Value** ![](../../../../../../images/6f7d68453797_EditAttributeValueIcon.jpg) icon. This opens the **Edit Attribute Value** window.

<a id="wwID0EBMFU"></a>

2. In this window, the **Set** drop-down menu displays all the attributes that you can edit and that are available in the **Add Baseline Objects** window. Select an attribute from this drop-down menu, for which you want to change the value.

<a id="wwID0ELNFU"></a>

3. From the **To** field, select a value that you want to change to. The values in this field change according to the attributes that you select in the **Set** drop-down menu. You can also click the **Set Default** button adjacent to the **To** field to use the selected value as the default value for the selected attribute.
