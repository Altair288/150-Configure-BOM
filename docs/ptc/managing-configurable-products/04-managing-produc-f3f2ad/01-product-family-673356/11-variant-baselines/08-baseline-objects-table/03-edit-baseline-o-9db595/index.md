# Edit Baseline Objects Window

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodfamily/ProdFamilyEditBaselineObjectsWindow.html)  
> 获取日期：2026-11-12

<a id="wwID0ERZFU"></a>

<a id="wwID0EH1FU"></a>

The **Edit Baseline Objects** window is used to edit the status of baseline objects that are associated with the variant baseline and other soft attributes on the baseline member link. As a prototype is developed, the status of component parts that are associated with the variant baseline can be tracked by assigning a value in the **Status** column of the **Baseline Objects** table.

<a id="wwID0EZ1FU"></a>

To open the **Edit Baseline Objects** window select the **Edit Baseline Objects** action from one of the following locations.

<a id="wwID0E12FU"></a>

- The **Actions** menu from a variant baseline information page.

<a id="wwID0EA4FU"></a>

- Edit baseline objects icon ![](../../../../../../images/76994d3648f4_IconLotBaselineEdit.png) in the **Baseline Objects** table tool bar on a Product Family structure tab or variant baseline information page.

<a id="wwID0EO5FU"></a>

- The **Actions** menu in the **Baseline Objects** table tool bar on a Product Family **Structure** tab or variant baseline information page.

<a id="wwID0EN6FU"></a>

In the **Edit Baseline Objects** window, you can edit the **Status** column of individual parts from the **Baseline Objects** table. The **Status** column is used to report where in the prototype development process the part is. Select from the following:

<a id="wwID0EWAGU"></a>

- In Work

<a id="wwID0EYBGU"></a>

- In Procurement

<a id="wwID0E1CGU"></a>

- In Assembly

<a id="wwID0EN6FU-10"></a>

When the status of a part is changed to **In Assembly**, the part is then locked to protect it from further change. The **Baseline object association lock status** column in the **Baseline Objects** table displays the locked icon ![](../../../../../../images/016d257919c2_GlyphLocked.gif). The locked icon is also displayed in matrix editor cells for locked parts within a variant baseline column.

<a id="wwID0ECEGU"></a>

To edit the attributes values for baseline objects, select a baseline object and click the **Edit Attribute Value** ![](../../../../../../images/6f7d68453797_EditAttributeValueIcon.jpg) icon.

<a id="wwID0EUEGU"></a>

Business rules can be defined to specify the conditions when a baseline object is locked. .
