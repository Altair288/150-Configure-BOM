# Adding a Variant Specification to a Variant Baseline

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodfamily/ProdFamilyAddProductVariantToVariantBaseline.html)  
> 获取日期：2026-11-12

<a id="wwID0EVWBU"></a>

<a id="wwID0EGXBU"></a>

Use the following procedure to add a variant specification to an existing variant baseline.

<a id="wwID0E6XBU"></a>

1. From Product Family **Structure** tab, right-click the variant specification that you want to add to a variant baseline.

<a id="wwID0EFZBU"></a>

2. From the right-click actions menu, click ![](../../../../../images/5669a06a74e1_IconLotBaselineAdd.png) **Assign to Existing Variant Baseline**. The **Assign to Existing Variant Baseline** window displays.

<a id="wwID0EX1BU"></a>

3. Select a variant baseline.

<a id="wwID0E32BU"></a>

1. Click the find icon ![](../../../../../images/b6b1aa165f5e_IconFind.gif) next to the **Variant Baseline** field. The **Find Object** window displays.

<a id="wwID0EQ4BU"></a>

1. Specify your search criteria and click **Search**.

<a id="wwID0EW5BU"></a>

1. Select a variant baseline from the **Search Results** table and click **OK**.

<a id="wwID0EG5BU-2"></a>

1. Your selection is added to the **Assign to Existing Variant Baseline** window.

<a id="wwID0EGACU"></a>

4. If you want to add additional variant specifications to the variant baseline, click the add variant specifications icon ![](../../../../../images/95a4c9475784_IconAdd.gif). The **Find Variant Specifications** window displays.

<a id="wwID0EZBCU"></a>

1. Specify your search criteria and click **Search**.

<a id="wwID0E6CCU"></a>

1. From the **Search Results** table, select the variant specifications you want to add and click **OK**. Your selections are added to the **Assign to Existing Variant Baseline** window.

<a id="wwID0EOECU"></a>

5. On the **Assign to Existing Variant Baseline** window, confirm the variant specifications you want to add are listed in the **Variant Specifications** table, then click **OK**.

<a id="wwID0ENFCU"></a>

A confirmation message displays whether the variant specifications are successfully added to the variant baseline. If the variant baselines are displayed in the Product Family structure, then the structure updates with the variant specifications as children of the variant baseline.

<a id="wwID0ESFCU"></a>

Use the following procedure to add a variant specification to a new variant baseline.

<a id="wwID0ELGCU"></a>

1. From Product Family **Structure** tab, right-click the variant specification that you want to add to the new variant baseline.

<a id="wwID0ERHCU"></a>

2. From the right-click actions menu, click ![](../../../../../images/4f05850efa3c_Icon_NewVarBaseline.png) **Assign to New Variant Baseline**. The **Assign to New Variant Baseline** window displays.

<a id="wwID0EDJCU"></a>

3. In this window, specify a name and other details for the variant baseline that you are creating.

<a id="wwID0EFKCU"></a>

4. Click **Next**.

<a id="wwID0ELLCU"></a>

5. In the **Select Variant Specifications** section, select a variant specification listed in the table.

<a id="wwID0ERMCU"></a>

6. Click **Finish**.

<a id="wwID0EINCU"></a>

A confirmation message displays whether the variant specifications are successfully added to the variant baseline. If the variant baselines are displayed in the Product Family structure, then the structure updates with the variant specifications as children of the variant baseline.
