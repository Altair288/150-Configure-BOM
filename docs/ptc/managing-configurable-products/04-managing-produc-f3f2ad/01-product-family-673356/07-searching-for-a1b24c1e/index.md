<a id="wwID0E4PZT"></a>

<a id="wwID0EOQZT"></a>

Your administrator can set preferences that determine whether Product Family object types are displayed in the advanced and global search default types lists. For more information, see [Product Family Management Preferences](../13-product-famil-9fdce8c5/02-product-famil-d963a369/index.md#wwID0EOZOU "Product Family Management Preferences").

<a id="wwID0E5QZT"></a>

Product Family objects can be searched using the same methods for other Windchill objects. For more information, see [Windchill Search](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/search/LclSrchAbout.html).
