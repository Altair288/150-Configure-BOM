# Insert New Product Family Member

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodfamily/ProdFamilyInsertNewProdFamObject.html)  
> 获取日期：2026-11-12

<a id="wwID0EJE4T"></a>

<a id="wwID0E1E4T"></a>

To add a new member to a Product Family structure, use **Insert New** ![](../../../../../../images/9a198c927f5e_IconNew.gif) action. This opens the **Insert New Product Family Member** window. The action is available from the following locations.

<a id="wwID0EFG4T"></a>

- **Editing** action group on the Product Family **Structure** tab tool bar.

<a id="wwID0EOH4T"></a>

- In the Product Family structure, right-click to display actions on a Product Family member and select Insert > ![](../../../../../../images/9a198c927f5e_IconNew.gif) Insert New.

<a id="wwID0EZI4T"></a>

**Insert New** is unavailable when variant specification and variant baseline nodes are selected in the Product Family structure. These objects are terminal nodes and child nodes cannot be added below them.
