# Editing a Product Family Object

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodfamily/ProdFamilyEdit.html)  
> 获取日期：2026-11-12

<a id="wwID0EJ53T"></a>

<a id="wwID0E453T"></a>

To edit the attributes of a Product Family object, perform one of the following actions.

<a id="wwID0EV63T"></a>

- Select **Edit** from the **Actions** menu on a Product Family object’s information page. This action is applied only to the Product Family.

<a id="wwID0E6A4T"></a>

- Right-click a Product Family object in a Product Family **Structure** tab and click Edit > Edit.

<a id="wwID0EVC4T"></a>

- Select a Product Family object in a Product Family **Structure** tab and click **Edit** in the tab’s tool bar.

<a id="wwID0EQD4T"></a>

The title of the edit window matches the type of Product Family object that you are editing. For example, when editing a product model group, the **Edit Product Model Group** opens. From this window you can edit attributes; for example, the name and description.
