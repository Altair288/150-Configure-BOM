The following table describes the key actions that are available in the Matrix Editor tool bar:

| Action | Description |
| --- | --- |
| **Insert** | • **Insert New**: Opens the **New Part** window, from where you can insert a new part in the selected part structure. For more information, see [Creating a New Part](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/parts/PMPartCreate.html). For more information on attributes, see [Part Attributes](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/parts/PMPartAttributesRef.html). • **Insert Existing**: Opens the **Insert Existing** window, where you can insert one or more existing parts in the selected part structure. For more information, see [Inserting an Existing Part](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodstructure/PMChildPartAdd.html). |
| **Insert multiple new** | Opens the **New Multiple Parts** window, from where you can create and insert multiple parts in the product structure in a single operation. For more information, see [Creating Multiple New Parts](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/parts/PMPartMultipleCreate.html). |
| **Remove Selected** | Removes the selected part from the structure. The parent assembly part is automatically checked out, and remains checked out after the Remove action is complete. |
| **Edit Part** | Opens the **Edit Part** window, where you can edit the part attributes. For more information, see [Editing a Part](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/parts/PMPartUpdate.html). |
| **Edit Multiple Objects** | Opens the **Edit Multiple Parts** window, where you can edit multiple parts using one single operation. For more information, see [Editing Multiple Parts](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/parts/PMPartMultipleEdit.html). |
| **Edit Attribute Value** | Opens the **Edit Attribute Value** window, where you can configure the value for multiple selected objects in the configurable structure provided that the attributes that are to be edited must be configured in the current structure view. |
| **Edit Usage Attributes** | Opens the **Edit Usage Attributes** window, where you can edit the attributes on the usage link between a selected child part and the next higher assembly part. For more information, see [Editing Usage Attributes](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodstructure/PMUsageAttributesEdit.html#wwID0EWVMM "Editing Usage Attributes"). |
| Display > Hide unselected parts | Hides the configurable modules and module variants that are not selected by any of the displayed variant specifications, and parts that are filtered due to manual selection or option filtering. |
| **Filter** | Provides the following filtering options: • **Current Filter**: Opens the **Current Filter** window, where you can view the information related to configuration specification, spatial filter, attribute filter, and path filter. • **Edit Path Filter**: Opens the **Edit Path Filter** window, where you can clear, select, or reset all path filters. • **Apply Path Filter**: Applies the path filter to the parts that you have selected in the part structure tree. • **Disable Path Filter**: Removes the path filter applied to the parts in the part structure tree. • **Edit Filter**: Opens the **Edit Filter** window, where you can apply the configuration specifications to lower-level part structure. This allows you to view the structure for the variant specification. For more information, see [Editing a Structure Filter](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodstructure/PMFilterEdit.html#wwID0EXIDO "Editing a Structure Filter"). • **Saved Filters**: Allows you to apply saved filters. This replaces all the configuration specification entries with the entries defined in the saved filter. For more information, see [Saving and Reusing Structure Filters](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodstructure/PMFilterSave.html). For more information on filter actions, see [Filter Action Set — Parts](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodstructure/PMActionSetFilter.html#wwID0EBZAO "Filter Action Set - Parts") and [About Part Structure Filters](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodstructure/PMFilterAbout.html#wwID0ES3BO "About Part Structure Filters"). |

> ![\*](../../../../../images/6652ad397dd1_note_16x16.png) **Note:** For Check Out/In and Reports action sets, see [Check Out/In Action Set — Parts](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodstructure/PMActionSetCheckOutIn.html) and [Reports Action Set — Parts](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodstructure/PMStructureReports.html).
