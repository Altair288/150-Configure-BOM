This adds rows as children to the module variant master. One row is displayed for each revision of the selected module variant, and one additional row is displayed for the latest revision of the module variant.</div>

                </td>
                <td>
                  <div id="wwID0EPVKU">Removes module variants associated with the variant baseline.</div>
                  <div id="wwID0ETVKU">After you remove the association between the variant baseline and the module variants, the configurable part structure displays the appropriate revision of that module variant.</div>
                  <div id="wwID0EXVKU">When using multiple variant baselines, the status of the baseline member link is reverted to Undefined. When using a single variant baseline, the <span>Status</span> field is blank since the link is removed.</div>
                  <div id="wwID0EAWKU">You cannot use this action for the locked baseline objects.</div>

                <td>
                  <div id="wwID0EJXKU"><span>Select Module Variants</span></div>
                </td>
                <td>
                  <div id="wwID0EXXKU">Allows you to create manual selection rules that select module variants to define a variant specification solution. As a result:</div>
                  <div id="wwID0EPYKU"><span><span>• </span></span>This selects the module variants for each of the affected parent configurable modules that are currently defined by the manual selection filtering.</div>
                  <div id="wwID0ERZKU"><span><span>• </span></span>The affected parent configurable modules that are currently using option filtering are switched to using manual selection filtering. Also, you can create manual selection rules for each of these configurable modules to select all their children that were previously selected using option filtering, and to select the user-selected module variants.</div>
                  <div id="wwID0ET1KU"><span><span>• </span></span>The module variants appear as manually-selected items in the <span>Modules</span> tab of the Matrix Editor and on the <span>Structure</span> tab of the Product Family variant information page.</div>
                  <div>
                    <table>
                      <tr>
                        <td>
                          <div id="wwID0E12KU"><span><img src="../../../../../../images/6652ad397dd1_note_16x16.png" alt="*" width="16" height="16" /></span> </div>
                        </td>
                        <td>
                          <div id="wwID0E23KU"><span><span>• </span></span>This action is available only for module variants that are not selected for the applicable variant specifications.</div>
                          <div id="wwID0E44KU"><span><span>• </span></span>This action is not available if the <span>Create Configurable Module Manual Selection Rules</span> profile action is disabled using the user-defined Standard Profile.</div>
                          <div id="wwID0ED6KU"><span><span>• </span></span>All of the selected module variants are applicable, that is, their affected parent configurable modules are also included for the affected variant specifications.</div>
                          <div id="wwID0EFALU"><span><span>• </span></span>When you perform this action, all the affected variant specifications are automatically checked out and checked in.</div>
