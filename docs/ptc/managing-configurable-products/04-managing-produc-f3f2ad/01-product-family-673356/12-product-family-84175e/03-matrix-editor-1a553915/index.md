# Matrix Editor Product Family Pane

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodfamily/ProdFamilyMatrixEditorProdFamPane.html)  
> 获取日期：2026-11-12

<a id="wwID0E11HU"></a>

<a id="wwID0EL2HU"></a>

The Product Family pane in the Matrix Editor displays the Product Family from which the Matrix Editor was launched.

<a id="wwID0EQ2HU"></a>

Use this pane to select Product Family members to display the structure of the configurable module assigned to the Product Family in the matrix table in the center of the window. To display the configurable module structure in Matrix Editor, select the check box next to the objects in the Product Family structure pane and click **Apply** at the bottom of the pane.

<a id="wwID0E12HU"></a>

You can also edit the Product Family structure from Matrix Editor.

<a id="wwID0E62HU"></a>

The following actions are available from the Product Family pane tool bar in Matrix Editor.

| Action | Description |
| --- | --- |
| ![](../../../../../images/812898d24ac4_IconCustomize.gif) **Structure views (Default)** | Select a different view to display the Product Family structure table. To create a new view, click **Manage Structure Views** from the dropdown options. Contains the following options to define or change the display of the structure table: • **Default** • **Save Structure View** • **Manage Structure Views**: Opens the **Customize View List: Product Family Structure Tree** window, where you can select a different view to display the Product Family structure table. You can also create and edit new table views using the Edit action in this window. For more information, see [Creating and Editing New Table Views](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/usersetup_personal/UserSetupTableViewNew.html). |
| ![](../../../../../images/b6b1aa165f5e_IconFind.gif) **Show Find in Structure** | Displays a tool bar to search the Product Family structure. For more information, see [Find in Structure](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodstructure/PMFindInStructure.html#wwID0E3JBM "Find in Structure"). |

<a id="wwID0ECFIU"></a>

To expand or collapse the Product Family structure under a node, right-click the node, click **Expand by** and select the number of levels from the list, or click **Collapse All Levels** to view the top node.

<a id="wwID0EQFIU"></a>

For information on the shortcut menu actions available in this pane, see [Product Family Structure Tab Actions](../../08-creating-prod-12d7a84f/01-product-family-e9a2ce/index.md#wwID0E3WZT "Product Family Structure Tab").
