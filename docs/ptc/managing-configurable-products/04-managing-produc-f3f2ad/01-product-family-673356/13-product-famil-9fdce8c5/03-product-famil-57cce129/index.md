# Product Family Management Object Initialization Rules

<a id="wwID0EXPQU"></a>

The following Product Family management objects have attributes that are determined by object initialization rules out of the box.

| Object type | Attributes set by object initialization rule |
| --- | --- |
| Product Family | Life cycle Team template Number Organization |
| Product Model | Life cycle Team template Number Organization |
| Product Model Group | Life cycle Team template Number Organization |
| Variant Specification | Number Organization |
| Variant Baseline | Life cycle Team template Number Organization |

<a id="wwID0EXPQU-2"></a>

For more information, see [Object Initialization Rules](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/WCAdminContext/WCAdminContextContextAdminItemOIR.html).
