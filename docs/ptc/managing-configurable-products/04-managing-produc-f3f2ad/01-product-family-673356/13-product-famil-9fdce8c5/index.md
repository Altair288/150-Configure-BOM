<a id="wwID0EDQOU"></a>

The following section describes tools that administrators can use to manage the Product Family management module to modify out-of-the-box behaviors to match their business requirements.

<a id="wwID0EIQOU"></a>

Subtypes and reusable attributes of product family object types can be created using the [Type and Attribute Management ](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/typeattr/TypeMgrAbout.html) utility.

<a id="wwID0EYQOU"></a>

Policy rules, such as access control rules, can be defined for Product Family object types using the [Policy Administration](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/policyadmin/PolicyAdminAbout.html) utility.
