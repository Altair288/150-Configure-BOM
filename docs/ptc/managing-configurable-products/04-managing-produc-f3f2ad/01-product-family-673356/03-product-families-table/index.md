# Product Families Table

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodfamily/ProdFamilyTable.html)  
> 获取日期：2026-11-12

<a id="wwID0EZKYT"></a>

<a id="wwID0EJLYT"></a>

The **Product Families** table lists all of the product families that have been created within a product or library context. It is available from the **Product Families** tab on a product or library information page.

<a id="wwID0EXLYT"></a>

To navigate to the **Product Families** tab, perform these steps.

<a id="wwID0EUMYT"></a>

1. From the [Navigator](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/navigation/NavNavigatorAbout.html), expand the links below a product or library.

<a id="wwID0EFOYT"></a>

2. Select the **Product Families** link.

<a id="wwID0ELPYT"></a>

3. The application context’s information page displays with the **Product Families** tab selected.

<a id="wwID0ECQYT"></a>

From the table tool bar, you can add a new product family by clicking the new product family icon ![](../../../../images/8aaa5809470a_IconProductFamilyNew.png) to open the **New Product Family** window. For more information, see [Creating a New Product Family](../04-creating-a-ne-c85eeba2/index.md#wwID0EMRYT "Creating a New Product Family").
