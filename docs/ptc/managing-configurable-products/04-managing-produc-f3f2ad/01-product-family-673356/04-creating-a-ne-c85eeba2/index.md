# Creating a New Product Family

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/prodfamily/ProdFamilyNew.html)  
> 获取日期：2026-11-12

<a id="wwID0EMRYT"></a>

<a id="wwID0EASYT"></a>

A Product Family is the parent object under which a Product Family structure is created. A Product Family structure is used to organize similar products into a reusable structure comprised of product models and product model groups. Product families are created in **Product** ![](../../../../images/2dedd3528cf9_IconProduct.gif) or **Library** ![](../../../../images/34825043290b_IconLibrary.gif) contexts.

<a id="wwID0E4SYT"></a>

Create a Product Family using the **New Product Family** window. Use the following procedure to create a new Product Family.

<a id="wwID0E1TYT"></a>

1. Navigate to the [Product Families](../03-product-families-table/index.md#wwID0EZKYT "Product Families Table")[ table](../03-product-families-table/index.md#wwID0EZKYT "Product Families Table") of the **Product** ![](../../../../images/2dedd3528cf9_IconProduct.gif) or **Library** ![](../../../../images/34825043290b_IconLibrary.gif) context where you want to create the Product Family.

<a id="wwID0EEWYT"></a>

2. Select the **New Product Family** action from one of the following locations:

<a id="wwID0ENXYT"></a>

- The **Actions** menu, select New > New Product Family ![](../../../../images/8aaa5809470a_IconProductFamilyNew.png).

<a id="wwID0EMZYT"></a>

- The **New Product Family** ![](../../../../images/8aaa5809470a_IconProductFamilyNew.png) icon on the **Product Families** tab.

<a id="wwID0E61YT"></a>

3. If your administrator has defined multiple Product Family object types, then make a selection from the **Type** drop-down menu. Administrators can specify the default type through a preference.

<a id="wwID0EF3YT"></a>

4. Enter a name and description for the new Product Family.

<a id="wwID0EH4YT"></a>

5. Make a selection for any of the attributes that you are able to select. The following attributes may already be specified by your administrator through an object initialization rule.

<a id="wwID0EM5YT"></a>

- Number

<a id="wwID0EO6YT"></a>

- Life Cycle Template

<a id="wwID0EQAZT"></a>

- Team Template

<a id="wwID0ETBZT"></a>

6. Click **Next** to go to the **Set Security Labels** page. Security labels are a means to classify sensitive information and restrict access to only authorized users. For more information, see [Security Labels and Agreements](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/sublandingpages/SublandingPageSecurityLabel.html). This is an optional step and the **Set Security Labels** page is visible only when your site is using Security Labels.

<a id="wwID0ELDZT"></a>

7. Click **Finish** to complete the action. The [information page](../05-product-famil-e3c5226a/index.md#wwID0EUFZT "Product Family Information Page") for the new Product Family displays.
