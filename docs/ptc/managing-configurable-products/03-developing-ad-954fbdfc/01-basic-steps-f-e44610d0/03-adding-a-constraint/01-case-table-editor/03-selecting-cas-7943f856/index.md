# Selecting Case Table Parameters

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsCaseTableEditor_SelectingParams.html)  
> 获取日期：2026-11-12

<a id="wwID0EEEET"></a>

<a id="wwID0EYEET"></a>

Select parameters to include them in the case table:

<a id="wwID0ERFET"></a>

1. Select one or more parameters to be included in the case table.

<a id="wwID0ETGET"></a>

2. Specify whether the formulae are allowed in the case table:

<a id="wwID0EYHET"></a>

- Select the **No Formulae Allowed** radio button when the case table does not contain any formula.

<a id="wwID0E5IET"></a>

- Select the **Parameter Allows Formulae** radio button when the case table contains formulae.

|  |  |
| --- | --- |
| **![\*](../../../../../../images/6652ad397dd1_note_16x16.png)** | The **No Formulae Allowed** and **Parameter Allows Formulae** radio buttons are available only when the **Enable Advanced Case Tables** preference is enabled. |

<a id="wwID0ENLET"></a>

3. From the **Parameter Allows Formulae** drop-down list select the parameter allowing the formulae, when the **Parameter Allows Formulae** radio button is selected.

|  |  |
| --- | --- |
| **![\*](../../../../../../images/6652ad397dd1_note_16x16.png)** | Only parameters, that are supported for formulae and included in the case table, become available for selection. A parameter can be designated to allow formulae for a given case table. |

<a id="wwID0ERNET"></a>

4. Click **OK**.

<a id="wwID0EYEET-2"></a>

For information on editing formulae, see [Editing a Parameter Formula](../02-editing-a-param-4b0554/index.md#wwID0EA1DT "Editing a Parameter Formula").
