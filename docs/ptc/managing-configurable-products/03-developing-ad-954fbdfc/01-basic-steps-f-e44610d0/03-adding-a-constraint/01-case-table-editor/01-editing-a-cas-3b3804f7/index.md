# Editing a Case Table Parameter

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsCaseTableEditor_Parameters.html)  
> 获取日期：2026-11-12

<a id="wwID0ELNDT"></a>

<a id="wwID0E6NDT"></a>

In the **Edit Case Table Parameter** window, you can set the permissible values for a parameter for the selected parameter types:

> ![\*](../../../../../../images/6652ad397dd1_note_16x16.png) **Note:** The **Edit Case Table Parameter** icon is available in the Case Table Editor only when the **Enable Advanced Case Tables** preference is enabled.

<a id="wwID0EAQDT"></a>

1. In the **Edit Case Table Parameter** window, select how the value is set and the appropriate values. The combination of possibilities depends on the parameter type:

<a id="wwID0EJRDT"></a>

- **Selected Values**: Permissible values are identified with the selection or specification of one or more values. A selection list is provided for parameters defined with a list constraint. A list of entries can be made for suitable parameters without a list constraint.

<a id="wwID0EOSDT"></a>

- **Not Selected Values**: Values that are not permissible are identified with the selection or specification of one or more values. A selection list is provided for parameters defined with a list constraint. A list of entries can be made for suitable parameters without a list constraint.

<a id="wwID0ETTDT"></a>

- **Specify Range**: Specifies the permissible range of values for Integer or Real Number parameter types. For more information, see [Specifying a Parameter Range](../../../01-adding-a-parameter/01-editing-a-parameter/02-constraint-ta-37f5a979/01-specifying-a-pa-eb4b86/index.md#wwID0EZH6S "Specifying a Parameter Range").

<a id="wwID0ECVDT"></a>

- **All**: All values are permissible.

<a id="wwID0EHWDT"></a>

- **N/A**: No value is permitted for this parameter. Applicable only for parameters that are not mandatory.

<a id="wwID0EMXDT"></a>

- **ELSE**: Any value, not permitted elsewhere in the case table for this parameter, is permitted.

<a id="wwID0ETYDT"></a>

2. Click **OK**.
