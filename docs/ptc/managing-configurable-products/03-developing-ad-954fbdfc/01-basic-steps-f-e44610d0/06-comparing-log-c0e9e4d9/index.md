# Comparing Logic Between Two Configurable Modules

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OVLogicCompare.html)  
> 获取日期：2026-11-12

<a id="wwID0EV6FT"></a>

<a id="wwID0EJAGT"></a>

The Logic Comparison Report allows you to compare logic between two configurable modules.

<a id="wwID0ENAGT"></a>

To compare logic between two configurable modules:

<a id="wwID0EFBGT"></a>

1. Go to the information page of a configurable module. From the **Actions** menu, choose Compare > Compare Logic.

<a id="wwID0E2CGT"></a>

2. Fill in the search criteria to locate a configurable module that you want to use for the comparison, and click **Search**.

<a id="wwID0EBEGT"></a>

3. Select the part, and click **OK**.

<a id="wwID0EHFGT"></a>

4. Select the checkboxes for the logic information you want to display in the report, and click **OK**. The **Logic Comparison Report** displays differences between the objects.

<a id="wwID0EFAGT-3"></a>

The Logic Comparison Reports are also available for configurable modules to compare the logic of two iterations of the part in the **Version History** table under the **History** tab of the part information page.
