# Editing a Parameter

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsParameterEdit.html)  
> 获取日期：2026-11-12

<a id="wwID0E3M4S"></a>

<a id="wwID0EMN4S"></a>

To edit parameters:

<a id="wwID0EFO4S"></a>

1. Open a configurable module in the Part Structure Browser.

<a id="wwID0EIP4S"></a>

2. Click the **Parameters** tab.

<a id="wwID0EOQ4S"></a>

3. Select a row for the parameter you want to edit and click ![](../../../../../images/9dbb36b32ff3_IconEdit.gif).

<a id="wwID0EXR4S"></a>

4. The **Edit Parameter** window opens with the following tabs:

<a id="wwID0EQS4S"></a>

- [Information](01-information-t-33602fc6/index.md#wwID0ESX4S "Information Tab of the Edit Parameter Window")–Allows you to modify the parameter name and description.

<a id="wwID0EKT4S"></a>

- [Constraint](02-constraint-ta-37f5a979/index.md#wwID0EOR5S "Constraint Tab of the Edit Parameter Window")–Allows you to modify or add new constraints.

<a id="wwID0EEU4S"></a>

- [Equivalency](03-equivalency-t-b05f2fa3/index.md#wwID0EYX6S "Equivalency Tab of the Edit Parameter Window")–Allows you to modify equivalency rules for the parameter.

<a id="wwID0E5U4S"></a>

- [User Interface](04-user-interfac-762e0fe2/index.md#wwID0E566S "User Interface Tab of the Edit Parameter Window")–Allows you to modify the property values for the user interface.

<a id="wwID0EJW4S"></a>

5. When finished editing the parameter, click **Finish**.
