# Enabling the Selection of Multiple Values for a Parameter

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsParamMultiValueSel.html)  
> 获取日期：2026-11-12

<a id="wwID0E3SAT"></a>

<a id="wwID0EMTAT"></a>

You can enable the ability to select multiple values for a parameter from a list of allowed values.

<a id="wwID0ERTAT"></a>

When you select multiple values for a parameter, the configuration process may produce multiple solutions, and you can use each solution to generate a different variant. If parameters are driven using constraints, multiple value selection for driving parameters is propagated to driven parameters.

<a id="wwID0EWTAT"></a>

To enable the selection of multiple values from a list of allowed parameter values:

<a id="wwID0EPUAT"></a>

1. Open a configurable module in the Part Structure Browser and click the **Parameters** tab.

<a id="wwID0EVVAT"></a>

2. Select a parameter for which you want to enable multiple value selection.

<a id="wwID0EXWAT"></a>

3. Click ![](../../../../../../../images/9dbb36b32ff3_IconEdit.gif) to open the **Edit Parameter** window.

<a id="wwID0EGYAT"></a>

4. Click the **User Interface** tab on the **Edit Parameter** window.

<a id="wwID0EQZAT"></a>

5. Set the value of the multiselect property to Yes and click **Finish**.
