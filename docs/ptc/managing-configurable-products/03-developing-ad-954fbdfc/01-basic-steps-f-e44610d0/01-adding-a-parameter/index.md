# Adding a Parameter

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsParameterAdd.html)  
> 获取日期：2026-11-12

<a id="wwID0EHC4S"></a>

<a id="wwID0EXC4S"></a>

To add parameters to a configurable module:

<a id="wwID0EQD4S"></a>

1. Open the configurable module in the Part Structure Browser.

<a id="wwID0ESE4S"></a>

2. Click the **Parameters** tab.

<a id="wwID0EYF4S"></a>

3. Click ![](../../../../images/0c9813ba64b2_Exp_IconAddParameter.gif).

<a id="wwID0EBH4S"></a>

4. The **Create Parameter** window opens with the following tabs:

<a id="wwID0E1H4S"></a>

- [Information](01-editing-a-parameter/01-information-t-33602fc6/index.md#wwID0ESX4S "Information Tab of the Edit Parameter Window")–Allows you to specify a description and provide the information on how the parameter is defined, and also determine how the parameter is specified.

<a id="wwID0EUI4S"></a>

- [Constraint](01-editing-a-parameter/02-constraint-ta-37f5a979/index.md#wwID0EOR5S "Constraint Tab of the Edit Parameter Window")–Allows you to specify the parameter constraints, which can be a value range, a set of values, or a dynamic list.

<a id="wwID0EOJ4S"></a>

- [Equivalency](01-editing-a-parameter/03-equivalency-t-b05f2fa3/index.md#wwID0EYX6S "Equivalency Tab of the Edit Parameter Window")–Allows you to define equivalency rules for the parameter.

<a id="wwID0EIK4S"></a>

- [User Interface](01-editing-a-parameter/04-user-interfac-762e0fe2/index.md#wwID0E566S "User Interface Tab of the Edit Parameter Window")–Allows you to specify the property values for the user interface.

<a id="wwID0ETL4S"></a>

5. When finished defining the parameter, click **Finish**.
