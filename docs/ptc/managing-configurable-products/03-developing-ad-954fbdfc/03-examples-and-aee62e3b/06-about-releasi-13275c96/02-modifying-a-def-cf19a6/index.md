# Modifying a Default Baseline

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/WCOVModifyDefaultBaseline.html)  
> 获取日期：2026-11-12

<a id="wwID0EB6ST"></a>

<a id="wwID0ER6ST"></a>

Each revision of a topmost configurable module may have one and only one default baseline. Therefore, if you create a second managed baseline for the same revision of the topmost configurable module, the second managed baseline is designated as the default baseline for this configurable module, replacing the original managed baseline.

> ![\*](../../../../../images/6652ad397dd1_note_16x16.png) **Note:** The original managed baseline is retained in Windchill in its original form except that it is no longer be designated as the default baseline.
