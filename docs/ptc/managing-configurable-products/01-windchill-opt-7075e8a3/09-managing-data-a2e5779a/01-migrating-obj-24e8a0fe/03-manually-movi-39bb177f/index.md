# Manually Moving Migrated Objects to Products and Libraries

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsMoveObjects.html)  
> 获取日期：2026-11-12

<a id="wwID0E2UXS"></a>

<a id="wwID0E6VXS"></a>

1. Log in as a Site or Organization Administrator.

<a id="wwID0EBXXS"></a>

2. Search for a migrated option set using Advanced search. Add **Option Set** as the object type to search for.

<a id="wwID0EHYXS"></a>

3. Specify the context within which you want to search and click **Search**.

<a id="wwID0ENZXS"></a>

4. In the search results, locate the migrated option set.

<a id="wwID0EP1XS"></a>

5. Right-click the option set that you want to move and select **Move Option Set**.

<a id="wwID0EV2XS"></a>

6. In the **Move Option Set** window, specify a product or library where you want to move the option set.

<a id="wwID0EN3XS"></a>

After you moved the migrated option set, you can view its information page.
