# Customizing the Display Name of the Option Type

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsCustomOptionTab.html)  
> 获取日期：2026-11-12

<a id="wwID0ERDTQ"></a>

<a id="wwID0EBETQ"></a>

You can customize the display name of the option type that appears in the user interface. To do that, an administrator must rename the display name as follows:

<a id="wwID0E1ETQ"></a>

1. Log on as a site administrator, and go to Utilities > Type and Attribute Management.

<a id="wwID0EOGTQ"></a>

2. Under the option type, select the subtype to edit (for example, Sales Option).

|  |  |
| --- | --- |
| **![\*](../../../../images/6652ad397dd1_note_16x16.png)** | If you want to rename a custom option subtype, it must a peer to the out-of-the box subtypes (that is, Design Option and Sales Option). |

<a id="wwID0EKITQ"></a>

3. Edit the type and change its display name.
