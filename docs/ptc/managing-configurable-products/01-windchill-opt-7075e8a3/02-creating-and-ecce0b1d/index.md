# Creating and Managing Enterprise-wide Definitions

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsManagingOview.html)  
> 获取日期：2026-11-12

<a id="wwID0EQTQQ"></a>

<a id="wwID0EAUQQ"></a>

To support one or more product families, an Option Manager creates definitions that describe variability within product configurations. Based on these definitions, the Option Manager uses Windchill to create options and choices for a product or library context.

<a id="wwID0ERUQQ"></a>

Options and choices, defined for a Windchill product or library, with selection rules that govern the relationships among choices, make up an **option pool** of options available for reuse. From one or more option pools an Option Manager or Product Manager can create an **option set** to define a product family.

<a id="wwID0EFVQQ"></a>

## Who Can Manage Options?

<a id="wwID0EJVQQ"></a>

An Option Manager can create and manage options and choices for the container in which they are a member. The role of the Option Manager is available out-of-the-box. Organization administrators can add any existing user to the Option Manager team role.

> ![\*](../../../images/6652ad397dd1_note_16x16.png) **Note:** To work with an option pool, make sure the **Configurable Module Support** preference is set to **Yes**.
