# Editing an Option

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsEdit.html)  
> 获取日期：2026-11-12

<a id="wwID0EKSYQ"></a>

<a id="wwID0E1SYQ"></a>

After an option is created, you can edit the option to:

<a id="wwID0ETTYQ"></a>

- Change the setting for the **Required** attribute to indicate whether that option is required. Required options cannot be skipped during the choice assignment or selection. For more information, see [Options and Choices](../../../01-options-and-choices/index.md#wwID0EEXQQ "Options and Choices").

<a id="wwID0EDVYQ"></a>

- Change the setting for the **Single Choice Selection** attribute to indicate whether the option allows only one choice to be selected from the choices that exist for this option. For more information about single choice selection options, see [Options and Choices](../../../01-options-and-choices/index.md#wwID0EEXQQ "Options and Choices").

<a id="wwID0ETWYQ"></a>

- Edit the description.

<a id="wwID0EHXYQ"></a>

To edit an option:

<a id="wwID0EAYYQ"></a>

1. Go to the **Option Pool** tab under the product or library.

<a id="wwID0EGZYQ"></a>

2. Click the **Design Option** or **Sales Option** tab in the right pane.

<a id="wwID0EQ1YQ"></a>

3. Right-click the option and then select **Edit**.

<a id="wwID0EW2YQ"></a>

4. Edit the settings and click **OK**.
