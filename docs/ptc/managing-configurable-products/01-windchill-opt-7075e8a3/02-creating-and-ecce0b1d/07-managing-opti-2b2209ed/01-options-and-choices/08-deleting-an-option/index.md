# Deleting an Option

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsOptionDelete.html)  
> 获取日期：2026-11-12

<a id="wwID0E24YQ"></a>

<a id="wwID0EL5YQ"></a>

You cannot delete an option if the option is:

<a id="wwID0EE6YQ"></a>

- A member of an option set

<a id="wwID0EGAZQ"></a>

- Referenced by a rule (for example, include rule)

<a id="wwID0EIBZQ"></a>

- Assigned to configurable modules

<a id="wwID0E2BZQ"></a>

To delete an option:

<a id="wwID0EUCZQ"></a>

1. Go to the **Details** page of a product or library.

<a id="wwID0E1DZQ"></a>

2. Select the **Option Pool** tab.

<a id="wwID0EAFZQ"></a>

3. In the tree view, right-click an option and select **Delete**.
