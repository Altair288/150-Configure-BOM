# Ensuring Name Uniqueness for Options and Choices

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptiionsNameUniqueness.html)  
> 获取日期：2026-11-12

<a id="wwID0EGP5Q"></a>

<a id="wwID0EWP5Q"></a>

You can use two preferences to control the uniqueness of the names for options and choices:

<a id="wwID0EPQ5Q"></a>

- The Option name uniqueness preference specifies whether the name for the option should be unique within:

<a id="wwID0EYR5Q"></a>

- The product or library where the option was created (this is the out-of-the-box setting)

<a id="wwID0E1S5Q"></a>

- The hosting organization for the product or library where the option was created

<a id="wwID0E3T5Q"></a>

- The entire site

<a id="wwID0E6U5Q"></a>

- The Choice name uniqueness preference specifies whether the name for the choice should be unique within:

<a id="wwID0EIW5Q"></a>

- The option for which the choice was created (this is the out-of-the-box setting)

<a id="wwID0EKX5Q"></a>

- The product or library where the choice was created

<a id="wwID0EMY5Q"></a>

- The hosting organization for the product or library where the choice was created

<a id="wwID0EOZ5Q"></a>

- The entire site

<a id="wwID0ED15Q"></a>

You need to be a Site Administrator to set these preferences.
