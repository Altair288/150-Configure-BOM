# Creating Textual and Numeric Choices

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsChoiceCreate.html)  
> 获取日期：2026-11-12

<a id="wwID0EFM2Q"></a>

<a id="wwID0EVM2Q"></a>

Once the options are created, you can add possible choices for each option.

<a id="wwID0E1M2Q"></a>

To create choices for an option:

<a id="wwID0ETN2Q"></a>

1. Go to the **Option Pool** tab.

<a id="wwID0EZO2Q"></a>

2. Expand the tree view to display the options, and click the option for which you want to add choices.

<a id="wwID0E2P2Q"></a>

3. Select the **Design Choice** or **Sales Choice** tab in the right pane.

<a id="wwID0EFR2Q"></a>

4. Right-click the option, and then click **New Choice**.

|  |  |
| --- | --- |
| **![\*](../../../../../images/887c9a51d571_tip_16x16.png)** | You can also do this in the right pane by using the **Choices** table toolbar action ![](../../../../../images/033cd2fc380c_IconChoiceNew.gif). |

<a id="wwID0EST2Q"></a>

5. The **New Choice** window opens. To add choices, click ![](../../../../../images/95a4c9475784_IconAdd.gif) and type the name and description for each choice.

<a id="wwID0E6U2Q"></a>

6. If you are creating choices for a numeric option, you must enter the value for each numeric choice. The value is entered in the default units.

|  |  |
| --- | --- |
| **![\*](../../../../../images/6652ad397dd1_note_16x16.png)** | Ability to create numeric choices is an advanced capability subject to a separate license entitlement. |

<a id="wwID0E3W2Q"></a>

7. When finished adding all choices for the option, click **OK**. The choices are added to the **Choices** table located in the right pane.
