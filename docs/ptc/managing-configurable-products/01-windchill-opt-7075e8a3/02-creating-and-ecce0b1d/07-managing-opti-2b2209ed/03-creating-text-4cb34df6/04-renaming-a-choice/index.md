# Renaming a Choice

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsChoiceRename.html)  
> 获取日期：2026-11-12

<a id="wwID0ER43Q"></a>

<a id="wwID0EB53Q"></a>

You can rename a choice after it was created.

<a id="wwID0EG53Q"></a>

The **Rename** action is available from the following locations:

<a id="wwID0ED63Q"></a>

- From the right-click menu when selecting a choice in the tree view (left pane) on the **Option Pool** tab

<a id="wwID0EJA4Q"></a>

- From the right-clock menu when selecting a choice in the **Design Choice** or **Sales Choice** (in the right pane) on the **Option Pool** tab

<a id="wwID0EXB4Q"></a>

- From the **Actions** drop-down list on the choice information page

|  |  |
| --- | --- |
| **![\*](../../../../../../images/887c9a51d571_tip_16x16.png)** | If a renamed choice is associated with a CAD document that was downloaded in a workspace when the rename occurred, that CAD document shows the old choice name. You can see the new choice name by removing and then re-adding the CAD document from the workspace. |
