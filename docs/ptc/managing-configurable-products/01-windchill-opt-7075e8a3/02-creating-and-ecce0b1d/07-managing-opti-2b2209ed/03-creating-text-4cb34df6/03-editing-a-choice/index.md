# Editing a Choice

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsChoicesEdit.html)  
> 获取日期：2026-11-12

<a id="wwID0ENW3Q"></a>

<a id="wwID0E4W3Q"></a>

You can change the choice description after the choice is created.

<a id="wwID0E1X3Q"></a>

1. Go to the **Option Pool** tab.

|  |  |
| --- | --- |
| **![\*](../../../../../../images/887c9a51d571_tip_16x16.png)** | You can filter the list to show the design or sales options and choices. |

<a id="wwID0E3Z3Q"></a>

2. In the tree view in the left pane, expand a group or an option to show the related choices.

<a id="wwID0E513Q"></a>

3. Right-click a choice and click **Edit**. The **Edit** window appears.

<a id="wwID0EI33Q"></a>

4. Change the description and click **OK**.
