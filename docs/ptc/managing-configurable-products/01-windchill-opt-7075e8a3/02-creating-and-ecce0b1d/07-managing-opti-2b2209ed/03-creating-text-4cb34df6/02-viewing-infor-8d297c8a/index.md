# Viewing Information About a Choice

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsChoiceInfoPage.html)  
> 获取日期：2026-11-12

<a id="wwID0EJH3Q"></a>

<a id="wwID0EZH3Q"></a>

To view information about a choice:

<a id="wwID0ESI3Q"></a>

1. Go to the tree view in the left pane of the **Option Pool** page, or the **Structure** tab under the option set information page.

<a id="wwID0E3J3Q"></a>

2. Locate the choice and click ![](../../../../../../images/d371d2ffb4ed_IconInfoPage.gif). The information page identifies the choice type, the option, and the group to which the choice belongs, and provides a description.

<a id="wwID0EWK3Q"></a>

You can view information on where the choice is used by adding a new tab, and then selecting Customize > General > Where Used. The following information is available from the **Where Used** tab:

<a id="wwID0EKM3Q"></a>

- Click **Where Assigned** to view the **Assigned to Following Objects** table.

<a id="wwID0EUN3Q"></a>

- Click **Option Set** to view the **Used in the Following Option Sets** table.

<a id="wwID0E5O3Q"></a>

- Click **Choice Rules** to view the **Used in the Following Choice Rules** table.

<a id="wwID0EIQ3Q"></a>

- Click **Aliases** to view the **Used in the Following Aliases** table.

<a id="wwID0EDR3Q"></a>

The following actions from the **Actions** menu may be of a particular interest to you:

| Action | Description |
| --- | --- |
| **Edit** | Edit the description for the choice. |
| **Delete** | Delete the choice from the option. |

> ![\*](../../../../../../images/6652ad397dd1_note_16x16.png) **Note:** The information page for the numeric choice lists the same attributes as for non-numeric choices, plus the choice value and the quantity of measure used.
