# Working With the Choices Table

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsChoicesTable.html)  
> 获取日期：2026-11-12

<a id="wwID0EK12Q"></a>

<a id="wwID0E112Q"></a>

When selecting an option in the left pane of the **Option Pool** page, all choices defined for this option can be displayed by selecting the **Design Choice** or **Sales Choice** tab in the right pane. The **Choices** table located in the right pane shows all choices of a particular type, design or sales, depending on the tab selected.

<a id="wwID0EQ22Q"></a>

From the **Choices** table, you can perform the following actions:

<a id="wwID0EN32Q"></a>

- Add a new choice to the option by clicking ![](../../../../../../images/033cd2fc380c_IconChoiceNew.gif) in the table’s toolbar. For more information, see [Creating Textual and Numeric Choices](../index.md#wwID0EFM2Q "Creating Textual and Numeric Choices").

<a id="wwID0EA52Q"></a>

- Delete a choice by clicking ![](../../../../../../images/22aa5ed232d8_IconDelete.gif) in the table’s toolbar.

<a id="wwID0EK62Q"></a>

- Edit a choice by right-clicking a choice and selecting **Edit Choice**. For more information, see [Editing a Choice](../03-editing-a-choice/index.md#wwID0ENW3Q "Editing a Choice").

<a id="wwID0E1A3Q"></a>

- View a description for the choice by clicking the ![](../../../../../../images/d371d2ffb4ed_IconInfoPage.gif) row-action in the table. For more information, see [Viewing Information about a Choice](../02-viewing-infor-8d297c8a/index.md#wwID0EJH3Q "Viewing Information About a Choice").

<a id="wwID0ENC3Q"></a>

- Move the choice from one option to another within the same Option Pool. For more information, see [Moving a Choice](../05-moving-a-choice/index.md#wwID0E5D4Q "Moving a Choice").

|  |  |
| --- | --- |
| **![\*](../../../../../../images/6652ad397dd1_note_16x16.png)** | The **Move** action is available only for string and numeric choices, and is unavailable for Boolean choices. |

<a id="wwID0ENE3Q"></a>

Consider the following tips for using the **Choices** table:

<a id="wwID0EKF3Q"></a>

- Choices have a Number attribute that can be used to locate the choice.

<a id="wwID0E3F3Q"></a>

- You can configure the table view to show the **Choice Numbers** and **Choice Values** columns.
