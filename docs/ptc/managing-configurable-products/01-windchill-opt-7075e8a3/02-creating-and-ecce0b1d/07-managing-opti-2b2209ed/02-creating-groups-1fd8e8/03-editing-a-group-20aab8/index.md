# Editing a Group of Options

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsGroupEdit.html)  
> 获取日期：2026-11-12

<a id="wwID0EB61Q"></a>

<a id="wwID0ER61Q"></a>

You can rename the group using **Edit Group** action.

<a id="wwID0EOA2Q"></a>

1. Go to the **Option Pool** tab.

<a id="wwID0EUB2Q"></a>

2. In the left pane of the **Option Pool** page, right-click a group and select **Edit**.

<a id="wwID0E5C2Q"></a>

3. The **Edit** window appears. Type a new name for the group.
