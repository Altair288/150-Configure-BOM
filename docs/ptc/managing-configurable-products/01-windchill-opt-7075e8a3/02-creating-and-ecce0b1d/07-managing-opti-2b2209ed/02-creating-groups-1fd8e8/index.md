# Creating Groups of Options

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsGroupsNew.html)  
> 获取日期：2026-11-12

<a id="wwID0E2B1Q"></a>

<a id="wwID0ELC1Q"></a>

Within an option pool, you can create multiple groups to organize options by categories.

<a id="wwID0EED1Q"></a>

1. Go to the **Option Pool** tab. In the left pane, right-click the top product node, and select **New Group** from the actions menu.

<a id="wwID0EOE1Q"></a>

2. The **New Group** window opens. Type the names of the groups you want to create. Click ![](../../../../../images/95a4c9475784_IconAdd.gif) to add more rows.

<a id="wwID0E2F1Q"></a>

3. Click **OK**.

<a id="wwID0ESG1Q"></a>

You can now assign options to these groups.
