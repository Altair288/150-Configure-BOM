# Deleting a Group

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsGroupDelete.html)  
> 获取日期：2026-11-12

<a id="wwID0EIE2Q"></a>

<a id="wwID0EYE2Q"></a>

You cannot delete a group if it contains options. To remove a group, you must first remove its options by doing one of the following:

<a id="wwID0ERF2Q"></a>

- Reassigning options to another group

<a id="wwID0ETG2Q"></a>

- Reassigning options to no group

<a id="wwID0EGH2Q"></a>

For more information on reassigning options, see [Assigning Options to Groups](../01-assigning-optio-90a76b/index.md#wwID0EKH1Q "Assigning Options to Groups").

<a id="wwID0EWH2Q"></a>

To delete a group:

<a id="wwID0EPI2Q"></a>

1. Go to the **Details** page of a product or library.

<a id="wwID0EVJ2Q"></a>

2. Select the **Option Pool** tab.

<a id="wwID0E2K2Q"></a>

3. In the tree view, right-click a group and click **Delete**.
