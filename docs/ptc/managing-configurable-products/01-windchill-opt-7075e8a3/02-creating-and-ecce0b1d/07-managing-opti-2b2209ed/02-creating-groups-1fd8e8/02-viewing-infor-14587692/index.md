# Viewing Information About a Group

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsGroupInfoPage.html)  
> 获取日期：2026-11-12

<a id="wwID0ELY1Q"></a>

<a id="wwID0E2Y1Q"></a>

To view a group’s information page, go to the tree view in the left pane (of the **Option Pool** or the **Option Set** page), locate the group, and click ![](../../../../../../images/982d5cdd18f1_Information_Icon.png).

<a id="wwID0EQZ1Q"></a>

On the Details tab, you can view the group attributes and the options included in the group.

<a id="wwID0EVZ1Q"></a>

You can also view the options that belong to the group by adding a tab and using Customize > General > Options.

<a id="wwID0EP11Q"></a>

The following actions are available from the **Actions** menu of the information page:

| Action | Description |
| --- | --- |
| **Edit** | Edit the name of the group. |
| **Delete** | Delete the group from the option pool. |
