# Tips for Choice Selection

<a id="wwID0EKK5Q"></a>

When working with the choice selection user interface, consider the following tips:

<a id="wwID0ETK5Q"></a>

- Keyword search using **Search in table** allows you to find options and choices that are not currently showing in the table by finding full or partial matches. You can search for options and choices by entering a string from a name or description. The **Search in table** filter works in combination with the group filter.

<a id="wwID0E4L5Q"></a>

- When previewing product variants, the user interface for choice selection is initially populated based on the existing variant specification.

<a id="wwID0E6M5Q"></a>

- You can configure the display of choices using the **Choice Display Format** preference. For details, see [Setting the Preference for Displaying Choices](../03-creating-text-4cb34df6/07-setting-the-p-a9dda536/index.md#wwID0ER24Q "Setting the Preference for Displaying Choices").

<a id="wwID0E6N5Q"></a>

- The Number attribute is displayed for options and choices. Choice numbers can be either autogenerated (default) or entered manually, depending on the OIR setting.
