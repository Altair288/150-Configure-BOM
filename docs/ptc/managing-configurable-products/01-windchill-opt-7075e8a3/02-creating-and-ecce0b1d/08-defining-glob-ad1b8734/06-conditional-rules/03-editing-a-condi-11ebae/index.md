# Editing a Conditional Rule

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionEditingCondlRules.html)  
> 获取日期：2026-11-12

<a id="wwID0EGYCR"></a>

<a id="wwID0EWYCR"></a>

To edit a conditional rule:

<a id="wwID0EPZCR"></a>

1. Go to the **Option Pool** page and select the **Conditional Rules** tab.

<a id="wwID0EZ1CR"></a>

2. In the **Conditional Rules** table, locate the rule you want to edit and open its information page.

<a id="wwID0E62CR"></a>

3. In the rule information page, select **Edit** from the **Actions** menu.

<a id="wwID0EJ4CR"></a>

4. The **Edit Conditional Rule** window opens.

<a id="wwID0EP5CR"></a>

5. You can edit expressions in the **If** section, the desired action, or the target choices in the **Then** section.

<a id="wwID0EZ6CR"></a>

6. Click **Finish**.
