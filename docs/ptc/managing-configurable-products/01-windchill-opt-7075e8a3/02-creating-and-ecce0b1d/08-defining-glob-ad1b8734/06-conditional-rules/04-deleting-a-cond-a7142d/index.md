# Deleting a Conditional Rule

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsDeleteConditionalRule.html)  
> 获取日期：2026-11-12

<a id="wwID0EEBDR"></a>

<a id="wwID0EUBDR"></a>

To delete a conditional rule:

<a id="wwID0ENCDR"></a>

1. Go to the **Option Pool** page and select the **Conditional Rules** tab.

<a id="wwID0EXDDR"></a>

2. In the **Conditional Rules** table, right-click the rule that you want to edit and select **Delete**.
