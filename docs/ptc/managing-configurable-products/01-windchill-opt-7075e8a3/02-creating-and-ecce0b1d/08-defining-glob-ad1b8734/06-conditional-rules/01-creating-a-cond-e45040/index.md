# Creating a Conditional Rule

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsCreatingCondRules.html)  
> 获取日期：2026-11-12

<a id="wwID0E3YAR"></a>

<a id="wwID0EMZAR"></a>

To create a conditional rule:

<a id="wwID0EF1AR"></a>

1. Go to the **Option Pool** page and click the top-level node in the tree in the left pane.

<a id="wwID0EL2AR"></a>

2. Select the **Conditional Rules** tab in the right pane.

<a id="wwID0ER3AR"></a>

3. Click ![](../../../../../../images/1672457aff60_IconChoiceRulesNew.gif).

<a id="wwID0E14AR"></a>

4. The **New Conditional Rule** window opens. Provide the description for the rule.

<a id="wwID0EA6AR"></a>

5. Enter an expression in the **If** section of the window. You can add multiple expressions by adding rows to the table. Click ![](../../../../../../images/95a4c9475784_IconAdd.gif) to add more rows. Expressions in each row are combined using OR.

<a id="wwID0ENABR"></a>

6. In the **Then** section of the window, select the appropriate action.

<a id="wwID0ETBBR"></a>

7. In the **Then** section, enter the choices that are the target of the selected action.

<a id="wwID0EZCBR"></a>

8. Click **Finish**.
