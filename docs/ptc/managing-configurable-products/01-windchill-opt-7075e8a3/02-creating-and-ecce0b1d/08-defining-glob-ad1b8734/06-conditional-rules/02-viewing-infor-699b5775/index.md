# Viewing Information About a Conditional Rule

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsChoiceRuleRuleInfoPage.html)  
> 获取日期：2026-11-12

<a id="wwID0EQICR"></a>

<a id="wwID0EBJCR"></a>

To view information about a rule:

<a id="wwID0E1JCR"></a>

1. In the left pane of the **Option Pool** tab, select the top-level node in the tree view.

<a id="wwID0EALCR"></a>

2. Click the **Conditional Rules** in the right pane. The **Conditional Rules** table lists all conditional rules defined for the option pool.

<a id="wwID0EKMCR"></a>

3. Locate the rule and click ![](../../../../../../images/344d726c8e5e_icon_ViewInfo.png) in the **Conditional Rules** table to view the complete rule definition.

|  |  |
| --- | --- |
| **![\*](../../../../../../images/887c9a51d571_tip_16x16.png)** | You can also hover the mouse over the rule entry or use the **View Information** right-click action to view the complete rule definition. |

<a id="wwID0EJOCR"></a>

Option sets containing this rule can be viewed in the **Used in the Following Option Sets** table located under the **Where Used** tab.

<a id="wwID0EXOCR"></a>

You can also customize the information page and add the **Effectivity** table for the rule.

<a id="wwID0EBPCR"></a>

The following actions are available when you right-click a rule entry in the **Conditional Rules** table:

<a id="wwID0E6PCR"></a>

- **View Information**– View the details of the rule, such as number, description, definition, and so on.

<a id="wwID0EERCR"></a>

- **Set State**– Set the lifecycle state for the rule.

<a id="wwID0EJSCR"></a>

- **Copy**– Copy the rule to the clipboard.

<a id="wwID0EOTCR"></a>

- **Edit**–Edit the rule by reselecting choices related by the rule.

<a id="wwID0ETUCR"></a>

- **Delete**–Delete the rule from the option pool.

<a id="wwID0EYVCR"></a>

- **Revise**–Create a new revision of the rule.

<a id="wwID0E4WCR"></a>

- **New**–Create change management objects using this rule.
