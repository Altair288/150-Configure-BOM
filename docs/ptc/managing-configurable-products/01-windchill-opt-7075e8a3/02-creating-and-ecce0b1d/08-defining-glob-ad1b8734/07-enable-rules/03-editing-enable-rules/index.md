# Editing Enable Rules

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsEnableRulesEdit.html)  
> 获取日期：2026-11-12

<a id="wwID0EJGER"></a>

<a id="wwID0EZGER"></a>

After a rule is created, you can change the choices related by the rule.

<a id="wwID0ECHER"></a>

1. Go to the **Enable Rules** tab under the **Option Pool** tab. To display the **Enable Rule** tab, click the top-level node in the tree view, located in the left pane of the **Option Pool** page.

<a id="wwID0ETIER"></a>

2. Right-click an enable rule and select **Edit**.

|  |  |
| --- | --- |
| **![\*](../../../../../../images/887c9a51d571_tip_16x16.png)** | You can also do this action by right-clicking the source choice in the left pane, and then selecting **Edit**. |

<a id="wwID0E1KER"></a>

3. In the **Edit Enable Rule** window, reselect the target choices, and click **OK**.

|  |  |
| --- | --- |
| **![\*](../../../../../../images/6652ad397dd1_note_16x16.png)** | If you unselect all target choices while editing a rule and click **OK**, the rule is deleted. |
