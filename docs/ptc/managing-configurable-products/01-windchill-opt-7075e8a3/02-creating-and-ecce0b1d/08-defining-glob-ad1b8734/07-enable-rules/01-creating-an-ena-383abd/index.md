# Creating an Enable Rule

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsEnableRulesCreate.html)  
> 获取日期：2026-11-12

<a id="wwID0E3IDR"></a>

<a id="wwID0EMJDR"></a>

To create an enable rule:

<a id="wwID0EFKDR"></a>

1. Expand options in the left pane of the **Option Pool** page and locate a choice that you want to be the source choice.

<a id="wwID0ELLDR"></a>

2. Right-click the source choice, and then click **New Enable Rule**. The **New Enable Rule** window opens.

|  |  |
| --- | --- |
| **![\*](../../../../../../images/6652ad397dd1_note_16x16.png)** | The **New Enable Rule** action is available only if the selected choice is not a target choice of any existing global enable rule. |

|  |  |
| --- | --- |
| **![\*](../../../../../../images/6652ad397dd1_note_16x16.png)** | You cannot create an enable rule on the merged choices that were added from a lower-level option set. If you wish to create rules on those choices, you need to remove them from the merged option set. For more information on removing the merged choices, see [Removing Merged Choices and Rules](../../../../03-working-with-op-fa126a/05-merging-option-sets/03-removing-merg-b3cafce6/index.md#wwID0E2EVR "Removing Merged Choices and Rules"). |

<a id="wwID0EZODR"></a>

3. Provide a description for the rule.

<a id="wwID0E2PDR"></a>

4. Select the target choices to associate with the source choice. To select the target choices:

<a id="wwID0EARDR"></a>

1. Click the appropriate option tab.

<a id="wwID0ECSDR"></a>

1. Select an option from the table list.

<a id="wwID0EETDR"></a>

1. Click the choices that you want to select in the right pane of the window.

<a id="wwID0EGUDR"></a>

1. If needed, select the next option to add additional choices.

<a id="wwID0EJVDR"></a>

5. Click **OK**. The enable rule is added to the **Enable Rules** table.
