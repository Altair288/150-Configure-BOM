# Exporting the Latest Iterations of all Versions of Choice Rules

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsExportingLatestChoiceRules.html)  
> 获取日期：2026-11-12

<a id="wwID0EYGAR"></a>

<a id="wwID0EIHAR"></a>

Out-of-the-box, when you export choice rules, only the latest iteration of the latest version is exported.

<a id="wwID0ENHAR"></a>

If you want to export the latest iteration of all existing versions of the choice rules, you must set the following wt.property to TRUE:

<a id="wwID0ESHAR"></a>

com.ptc.windchill.option.ixb.exportAllRuleVersions=true
