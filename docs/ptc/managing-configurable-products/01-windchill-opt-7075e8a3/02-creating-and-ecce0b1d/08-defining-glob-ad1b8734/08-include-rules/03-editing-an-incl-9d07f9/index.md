# Editing an Include Rule

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsIncludeRulesEdit.html)  
> 获取日期：2026-11-12

<a id="wwID0EGRFR"></a>

<a id="wwID0EWRFR"></a>

After a rule is created, you can change the choices related by the rule.

<a id="wwID0E6RFR"></a>

1. Go to the **Include Rules** tab under the **Option Pool** tab. To display the **Include Rule** tab, click the top-level node in the tree view, located in the left pane of the **Option Pool** page.

<a id="wwID0EQTFR"></a>

2. Right-click an include rule and select **Edit**.

|  |  |
| --- | --- |
| **![\*](../../../../../../images/887c9a51d571_tip_16x16.png)** | You can also do this action by right-clicking the source choice in the left pane, and then selecting **Edit Include Rule**. |

<a id="wwID0EWVFR"></a>

3. In the **Edit Include Rule** window, reselect the target choices, and click **OK**.

|  |  |
| --- | --- |
| **![\*](../../../../../../images/6652ad397dd1_note_16x16.png)** | If you unselect all target choices while editing a rule and click **OK**, the rule is deleted. |
