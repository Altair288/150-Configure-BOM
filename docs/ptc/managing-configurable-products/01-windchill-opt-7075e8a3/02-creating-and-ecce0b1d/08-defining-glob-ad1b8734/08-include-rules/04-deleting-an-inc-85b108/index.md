# Deleting an Include Rule

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsMappingsManage.html)  
> 获取日期：2026-11-12

<a id="wwID0ECYFR"></a>

<a id="wwID0ESYFR"></a>

To delete an include rule:

<a id="wwID0ELZFR"></a>

1. Go to the **Include Rules** tab under the **Option Pool** tab. To display the **Include Rules** tab, click the top-level node in the tree view, located in the left pane of the **Option Pool** page.

<a id="wwID0E51FR"></a>

2. In the **Include Rules** table, locate the rule. Select a checkmark and click ![](../../../../../../images/22aa5ed232d8_IconDelete.gif).
