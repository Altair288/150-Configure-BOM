# Include Rules

<a id="wwID0ECSER"></a>

Include rules capture a logical association between product features, ensuring that the correct choices are selected when a product structure is filtered. By introducing include rules, you enforce relationships among related choices, streamlining the selection of the choices for filtering a configurable structure.

<a id="wwID0EHSER"></a>

To create an include rule, you select a source choice and associate it with target choices, which are automatically selected when the source choice is selected. You can create include rules, mapping a sales choice to a number of design choices. For example, selecting a particular vehicle model in the Sales Configurator automatically selects the key features associated with that model.

<a id="wwID0EQSER"></a>

## Behavior of Include Rules with Different Options Types

<a id="wwID0EUSER"></a>

For options defined as a single-selection, you can select only one choice as a target choice for an include rule. This behavior is observed when filtering the product structure or previewing the option set.
