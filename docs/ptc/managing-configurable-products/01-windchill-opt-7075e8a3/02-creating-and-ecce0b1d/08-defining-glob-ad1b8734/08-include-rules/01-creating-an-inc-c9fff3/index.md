# Creating an Include Rule

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsMappingCreate.html)  
> 获取日期：2026-11-12

<a id="wwID0EBUER"></a>

<a id="wwID0ERUER"></a>

After options and choices are created, you can create include rules to relate the source choice to target choices. You can create rules from the tree view of the **Option Pool** page, or from the **Choices** table located under the **Design Choice** or **Sales Choice** tab.

<a id="wwID0EHVER"></a>

To create an include rule between choices:

<a id="wwID0EAWER"></a>

1. Locate a choice that you want to be the source choice by expanding options in the left pane of the **Option Pool** page.

<a id="wwID0EGXER"></a>

2. Right-click the source choice, and then click **New Include Rule**. The **New Include Rule** window opens.

|  |  |
| --- | --- |
| **![\*](../../../../../../images/6652ad397dd1_note_16x16.png)** | You cannot create an include rule on the merged choices that were added from a lower-level option set. If you wish to create rules on those choices, you need to remove them from the merged option set. For more information on removing the merged choices, see [Removing Merged Choices and Rules](../../../../03-working-with-op-fa126a/05-merging-option-sets/03-removing-merg-b3cafce6/index.md#wwID0E2EVR "Removing Merged Choices and Rules"). |

<a id="wwID0EWZER"></a>

3. Provide a description for the rule.

<a id="wwID0EY1ER"></a>

4. Select the target choices to associate with the source choice. To select the target choices:

<a id="wwID0E42ER"></a>

1. Click the appropriate option tab.

<a id="wwID0E63ER"></a>

1. Select an option from the table list.

<a id="wwID0EB5ER"></a>

1. Click the choices that you want to select in the right pane of the window.

<a id="wwID0ED6ER"></a>

1. If needed, select the next option to add additional choices.

<a id="wwID0EGAFR"></a>

5. Click **OK**. The include rule is added to the **Include Rules** table.
