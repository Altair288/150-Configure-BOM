# Deleting an Exclude Rule

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsConstraintsManage.html)  
> 获取日期：2026-11-12

<a id="wwID0ELAHR"></a>

<a id="wwID0E2AHR"></a>

The **Exclude Rules** table lists all exclude rules for the options defined for a product or library.

<a id="wwID0EFBHR"></a>

To delete an exclude rule:

<a id="wwID0E5BHR"></a>

1. Go to the **Exclude Rules** tab under the **Option Pool** tab. To display the **Exclude Rules** tab, click the top-level node in the tree view, located in the left pane of the **Option Pool** page.

<a id="wwID0EQDHR"></a>

2. In the **Exclude Rules** table, locate the rule. Select a checkbox and click ![](../../../../../../images/22aa5ed232d8_IconDelete.gif).
