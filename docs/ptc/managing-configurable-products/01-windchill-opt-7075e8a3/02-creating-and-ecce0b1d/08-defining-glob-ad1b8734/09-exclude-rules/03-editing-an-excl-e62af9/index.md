# Editing an Exclude Rule

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsExcludeRulesEdit.html)  
> 获取日期：2026-11-12

<a id="wwID0E41GR"></a>

<a id="wwID0EN2GR"></a>

After a rule is created, you can change the choices that are related by the rule.

<a id="wwID0EG3GR"></a>

1. Go to the **Exclude Rules** tab under the **Option Pool** tab. To display the **Exclude Rules** tab, click the top-level node in the tree view, located in the left pane of the **Option Pool** page.

<a id="wwID0EY4GR"></a>

2. Right-click an exclude rule and click **Edit**.

<a id="wwID0E55GR"></a>

3. In the **Edit Exclude Rule** window, change the selections of choices and click **OK**.
