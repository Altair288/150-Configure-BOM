# Viewing Information About an Exclude Rule

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsExcludeRuleInfoPage.html)  
> 获取日期：2026-11-12

<a id="wwID0ENLGR"></a>

<a id="wwID0EVMGR"></a>

1. In the left pane of the **Option Pool** tab, select the top-level node in the tree view.

<a id="wwID0E2NGR"></a>

2. Click the **Exclude Rules** tab in the right pane. The **Exclude Rules** table lists all exclude rules defined for the option pool.

<a id="wwID0EFPGR"></a>

3. Locate the rule and click ![](../../../../../../images/344d726c8e5e_icon_ViewInfo.png) to view the complete rule definition.

|  |  |
| --- | --- |
| **![\*](../../../../../../images/887c9a51d571_tip_16x16.png)** | You can also hover the mouse over the rule entry or use the **View Information** right-click action to view the complete rule definition. |

<a id="wwID0EBRGR"></a>

Option sets containing this rule can be viewed in the **Used in the Following Option Sets** table located under the **Where Used** tab.

<a id="wwID0EPRGR"></a>

You can also customize the information page and add the **Effectivity** table for the rule.

<a id="wwID0EZRGR"></a>

The following actions are available when you right-click a rule entry in the **Exclude Rules** table:

<a id="wwID0EWSGR"></a>

- **View Information**– View the details of the rule, such as rule number, description, definition, and so on.

<a id="wwID0E2TGR"></a>

- **Set State**– Set the lifecycle start for the rule.

<a id="wwID0EAVGR"></a>

- **Copy**– Copy the rule to the clipboard.

<a id="wwID0EFWGR"></a>

- **Edit**–Edit the rule by reselecting choices related by the rule.

<a id="wwID0EKXGR"></a>

- **Delete**–Delete the rule from the option pool.

<a id="wwID0EPYGR"></a>

- **Revise**–Create a new revision of the rule.

<a id="wwID0EUZGR"></a>

- **New**–Create change management objects using this rule.
