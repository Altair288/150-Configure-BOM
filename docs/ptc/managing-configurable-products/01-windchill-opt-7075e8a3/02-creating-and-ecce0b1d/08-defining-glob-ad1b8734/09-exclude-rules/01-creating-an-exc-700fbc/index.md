# Creating an Exclude Rule

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsConstraintsCreate.html)  
> 获取日期：2026-11-12

<a id="wwID0EN5FR"></a>

<a id="wwID0E45FR"></a>

After the options and choices are defined, you can create exclude rules between choices to prevent the selection of incompatible choices. You can create rules from the tree view of the **Option Pool** page, or from the **Choices** table located under the **Design Choice** or **Sales Choice** tab.

<a id="wwID0ET6FR"></a>

To create exclude rules:

<a id="wwID0EMAGR"></a>

1. Go to the **Exclude Rules** tab under the **Option Pool** tab. To display the **Exclude Rules** tab, click the top-level node in the tree view, located in the left pane of the **Option Pool** page.

<a id="wwID0E6BGR"></a>

2. In the **Exclude Rules** table, click the toolbar action ![](../../../../../../images/1672457aff60_IconChoiceRulesNew.gif). The **New Exclude Rule** window opens.

<a id="wwID0EQDGR"></a>

3. Provide a description for the rule.

<a id="wwID0ESEGR"></a>

4. Select the choices to associate:

<a id="wwID0EXFGR"></a>

1. Click the appropriate option tab.

<a id="wwID0EZGGR"></a>

1. Select an option from the table list.

<a id="wwID0E2HGR"></a>

1. Click the choices that you want to select in the right pane of the window.

<a id="wwID0E4IGR"></a>

1. If needed, select the next option to add additional choices.

<a id="wwID0EAKGR"></a>

5. Click **OK** to finish. The exclude rule is added to the **Exclude Rules** table.
