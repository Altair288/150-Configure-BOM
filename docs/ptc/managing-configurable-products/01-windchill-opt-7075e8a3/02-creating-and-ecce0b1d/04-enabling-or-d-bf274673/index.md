# Enabling or Disabling Sales and Design Subtypes

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsSalesDesignSubtypeEnable.html)  
> 获取日期：2026-11-12

<a id="wwID0EPHSQ"></a>

<a id="wwID0E6HSQ"></a>

Two types of options and choices are supported in Windchill out-of-the-box: sales and design. Out-of-the-box, the sales options and choices are defined as not instantiable, and they cannot be used for assignment and selection unless you make them instantiable.

> ![\*](../../../../images/6652ad397dd1_note_16x16.png) **Note:** If a site does not intend to use an out-of-the-box object subtype, the Site Administrator can make this subtype (Sales or Design) uninstantiable for the option and choice types. This prevents the creation of an option or choice that is defined as uninstantiable.

<a id="wwID0E6ISQ"></a>

To change the Instantiable attribute:

<a id="wwID0EYJSQ"></a>

1. Log in as a Site Administrator and select Utilities > Type and Attribute Management.

<a id="wwID0ELLSQ"></a>

2. Click **Manage Types** and locate the **Option** type.

<a id="wwID0EVMSQ"></a>

3. Select the subtype that you want to change: **Design Option** or **Sales Option**.

<a id="wwID0E6NSQ"></a>

4. Change the **Instantiable** attribute as needed and click **OK**.

<a id="wwID0EJPSQ"></a>

5. Locate the **Choice** type.

<a id="wwID0EPQSQ"></a>

6. Select the subtype that you want to change: **Design Choice** or **Sales Choice**.

<a id="wwID0EZRSQ"></a>

7. Change the **Instantiable** attribute as needed and click **OK**.

<a id="wwID0EDTSQ"></a>

8. Exit the **Type and Attribute Management** utility.
