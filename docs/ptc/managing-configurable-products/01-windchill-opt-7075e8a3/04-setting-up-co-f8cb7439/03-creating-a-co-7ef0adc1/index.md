# Creating a Configurable Module

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsConfigPartCreate.html)  
> 获取日期：2026-11-12

<a id="wwID0EF6VR"></a>

> ![\*](../../../../images/6652ad397dd1_note_16x16.png) **Note:** If you plan to define advanced selection logic for a configurable module or use a deliverable generation process, the configurable module cannot be a child of a standard part.

<a id="wwID0EEBWR"></a>

1. Go to the product’s **Folders** page, and click ![](../../../../images/fb6240c85696_IconPartNew.gif).

<a id="wwID0ERCWR"></a>

2. In the **New Part** window, select **Part** for **Type**.

<a id="wwID0E6DWR"></a>

3. Select **Yes** for **Configurable Module**.

<a id="wwID0EJFWR"></a>

4. Select **No** for **Create as End Item**.

<a id="wwID0ETGWR"></a>

5. Select **Yes** for **Collapsible**. When the part is defined as collapsible, it is replaced by one of its child parts when choices are applied to the structure.

<a id="wwID0E4HWR"></a>

6. Type the part name and specify other part attributes.

<a id="wwID0E6IWR"></a>

7. If you want to restrict the number of child parts that are allowed for the configurable module, specify the values for **Minimum Required** and **Maximum Allowed**. For more information on this restriction, see [Restricting the Number of Child Parts](../05-restricting-t-8740c98d/index.md#wwID0EBYWR "Restricting the Number of Child Parts").

<a id="wwID0ETKWR"></a>

8. Complete the part creation by clicking **Finish**.
