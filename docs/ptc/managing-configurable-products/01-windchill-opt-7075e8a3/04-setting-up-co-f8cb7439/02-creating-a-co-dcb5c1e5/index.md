# Creating a Configurable Product

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsConfigProdCreate.html)  
> 获取日期：2026-11-12

<a id="wwID0EOTVR"></a>

<a id="wwID0E5TVR"></a>

A top-level part of a configurable structure can be designated as a configurable product by setting it as an end item. A configurable product captures variations on the product level, and supports discrete product variants.

<a id="wwID0EDUVR"></a>

To create a configurable product:

<a id="wwID0E3UVR"></a>

1. Go to the product’s **Folders** page, and click ![](../../../../images/fb6240c85696_IconPartNew.gif).

<a id="wwID0EJWVR"></a>

2. In the **New Part** window, select **Part** for **Type**.

<a id="wwID0EXXVR"></a>

3. Select **Yes** for **Configurable Module**.

<a id="wwID0EBZVR"></a>

4. Select **Yes** for **Create as End Item**.

<a id="wwID0EL1VR"></a>

5. Select **No** for **Collapsible**.

<a id="wwID0EV2VR"></a>

6. Type the part name and specify additional attributes if necessary.

<a id="wwID0EX3VR"></a>

7. Complete the part creation by clicking **Finish**.

> ![\*](../../../../images/6652ad397dd1_note_16x16.png) **Note:** In addition to creating a configurable product, you can also change a configurable module into a configurable product by editing the part attributes and setting **Create as End Item** to **Yes**.
