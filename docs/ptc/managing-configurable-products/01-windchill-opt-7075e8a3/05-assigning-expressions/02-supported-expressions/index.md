# Supported Expressions

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsSupportedExpressions.html)  
> 获取日期：2026-11-12

<a id="wwID0E6MYR"></a>

<a id="wwID0EQNYR"></a>

If the Windchill Platform Structures module is installed, an administrator can set a preference to specify the type of expressions to use for defining optionality in a configurable product structure. The Windchill preference Supported Expressions (located in the Options and Variants section of the **Preference Management** utility) has the following values:

<a id="wwID0EHPYR"></a>

- Basic expressions only

<a id="wwID0ELQYR"></a>

- Advanced expressions only

<a id="wwID0EPRYR"></a>

- Both basic and advanced expressions

> ![\*](../../../../images/6652ad397dd1_note_16x16.png) **Note:** • Although both types of expressions can be created in the product structure when the preference is set to Both basic and advanced expressions, only one type can be assigned to an item. • The ability to assign advanced expressions is an advanced capability subject to a separate license entitlement.

<a id="wwID0EQVYR"></a>

You can set this preference for a site, organization, product, or library.
