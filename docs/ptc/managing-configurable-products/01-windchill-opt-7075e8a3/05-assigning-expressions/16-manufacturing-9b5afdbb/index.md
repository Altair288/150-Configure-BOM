# Manufacturing Process Deliverables

<a id="wwID0EIRCS"></a>

<a id="wwID0EYRCS"></a>

From a manufacturing process management perspective, choice assignment and configurations specified for MPMLink objects are maintained when transforming an eBOM into an mBom. Using equivalent link parts, you can maintain assigned items, part positioning, and part attributes. This functionality is also applicable to other MPMLink objects, such as resources, manufacturing standards, and process plans.

<a id="wwID0E4RCS"></a>

In Windchill explorers, the **Assigned Item Expressions** column shows the assigned choices.

<a id="wwID0ESSCS"></a>

You can edit the options and choices in the **Assigned Item Expressions** column of a checked out configurable item.
