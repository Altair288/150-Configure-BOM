# Deleting Aliases

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsDeletingAliases.html)  
> 获取日期：2026-11-12

<a id="wwID0EKXES"></a>

<a id="wwID0E1XES"></a>

You can delete an alias from the following locations:

<a id="wwID0ETYES"></a>

- From the **Actions** list on the alias information page

<a id="wwID0EZZES"></a>

- From the **Expression Aliases** table on the **Expression Aliases** tab accessible from the option pool page:

<a id="wwID0EG2ES"></a>

- By right-clicking an alias and selecting **Delete**

<a id="wwID0EL3ES"></a>

- By selecting an alias and clicking ![](../../../../images/22aa5ed232d8_IconDelete.gif) on the table toolbar

<a id="wwID0EU4ES"></a>

- By selecting **Delete** from the **Actions** list on the table toolbar

<a id="wwID0EQ5ES"></a>

Deleting an alias deletes all its revisions.

> ![\*](../../../../images/6652ad397dd1_note_16x16.png) **Note:** You cannot delete an alias if the alias is used in the logical expressions of other objects (for example, in an advanced expressions or a conditional rule).
