# Renaming Aliases

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsRenamingAliases.html)  
> 获取日期：2026-11-12

<a id="wwID0EDAFS"></a>

<a id="wwID0ETAFS"></a>

Use the **Rename** action to change the name or number (if allowed) of the alias.

<a id="wwID0E4AFS"></a>

To rename an alias:

<a id="wwID0EWBFS"></a>

1. Go to the **Option Pool** tab of the product or library.

<a id="wwID0E3CFS"></a>

2. Click the top-level node in the option pool tree.

<a id="wwID0E5DFS"></a>

3. Click the **Expression Aliases** tab.

<a id="wwID0EEFFS"></a>

4. Right-click an alias in the table and click **Rename**. Edit the name or number.

> ![\*](../../../../images/6652ad397dd1_note_16x16.png) **Note:** Alternatively, you can edit the alias name or number from its information page.
