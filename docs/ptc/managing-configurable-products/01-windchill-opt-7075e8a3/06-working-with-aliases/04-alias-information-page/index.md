<a id="wwID0E5HES"></a>

The information page for an alias has the following tabs:

<a id="wwID0EXIES"></a>

- **Details** – Shows basic attributes of the alias object.

<a id="wwID0E4JES"></a>

- **Change** – Shows the change objects that reference the alias.

<a id="wwID0ECLES"></a>

- **History** – Shows the maturity and version history for the object.

<a id="wwID0EHMES"></a>

- **Where Used** – Provides the “where used” information in the following tables:

<a id="wwID0EPNES"></a>

- Click **Where Assigned** to view the **Assigned to Following Objects** table that shows all parts and part usages that have assigned expressions that reference the selected alias.

<a id="wwID0EZOES"></a>

- Click **Choice Rules** to view the **Used in the Following Choice Rules** table shows all conditional rules that use the selected alias in its logic.

<a id="wwID0EDQES"></a>

- Click **Aliases** to view the **Used in the Following Aliases** table that shows all aliases that use the selected alias.
