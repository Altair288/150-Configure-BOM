# Revising Aliases

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsRevisingAliases.html)  
> 获取日期：2026-11-12

<a id="wwID0ESRES"></a>

<a id="wwID0ECSES"></a>

Aliases follow the same revision process as other Windchill objects.

<a id="wwID0EUSES"></a>

You can revise an alias from the following locations:

<a id="wwID0ENTES"></a>

- From the **Actions** list on the alias information page

<a id="wwID0ETUES"></a>

- From the **Expression Aliases** table on the **Expression Aliases** tab accessible from the option pool page:

<a id="wwID0EAWES"></a>

- By right-clicking an alias and selecting **Revise**
