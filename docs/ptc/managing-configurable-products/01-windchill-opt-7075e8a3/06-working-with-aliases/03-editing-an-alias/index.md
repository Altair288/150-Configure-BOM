# Editing an Alias

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsEditingAnAlias.html)  
> 获取日期：2026-11-12

<a id="wwID0EK6DS"></a>

<a id="wwID0E16DS"></a>

When you edit an alias, the system automatically checks it out for you and checks it back in when you are finished. After an edit, an alias is iterated.

<a id="wwID0E66DS"></a>

To edit an alias:

<a id="wwID0EYAES"></a>

1. Go to the **Option Pool** tab of the product or library.

<a id="wwID0E5BES"></a>

2. Click the top-level node in the option pool tree.

<a id="wwID0EADES"></a>

3. Click the **Expression Aliases** tab.

<a id="wwID0EGEES"></a>

4. Right-click an alias in the table and click **Edit**. Edit the description or the expression.
