# Unassigning an Option Set

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsSetUnregister.html)  
> 获取日期：2026-11-12

<a id="wwID0E3JSR"></a>

<a id="wwID0EQKSR"></a>

When you unassign an option set:

<a id="wwID0EJLSR"></a>

- The choices used in assigned basic expressions are preserved.

<a id="wwID0ELMSR"></a>

- The choices used in assigned advanced expressions appear with a strike-though.

<a id="wwID0ENNSR"></a>

- The option set is not deleted – it remains in the list of option sets available for your organization, but it is not associated with the part.

<a id="wwID0EEOSR"></a>

To unassign an option set:

<a id="wwID0E5OSR"></a>

1. Go to the information page of the part, product, or library.

<a id="wwID0EAQSR"></a>

2. Add a new tab, and select Customize > General > Assigned Option Set.

<a id="wwID0EIRSR"></a>

3. In the **Assigned Option Set** table, right-click the option set, and select ![](../../../../../images/ae4a236e741a_IconRemove.gif) **Un-assign**.

<a id="wwID0EZSSR"></a>

4. A warning appears informing you that the option set for this product will be removed. Click **OK** to proceed.
