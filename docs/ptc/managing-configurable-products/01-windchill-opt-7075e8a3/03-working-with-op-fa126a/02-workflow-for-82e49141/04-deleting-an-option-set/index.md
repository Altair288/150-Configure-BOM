# Deleting an Option Set

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsDeleteOptionSet.html)  
> 获取日期：2026-11-12

<a id="wwID0E3WJR"></a>

<a id="wwID0EMXJR"></a>

Deleting an option set deletes the selected revision of option set, and restores the latest iteration of the previous revision, including the corresponding choice rules and preference settings.

<a id="wwID0ERXJR"></a>

To delete an option set:

<a id="wwID0EKYJR"></a>

1. Go to the **Option Sets** table accessed from the Option Pool page by using Customize > General > Option Sets.

<a id="wwID0EH1JR"></a>

2. Select a revision of the option set to delete and click ![](../../../../../images/22aa5ed232d8_IconDelete.gif).

<a id="wwID0EQ2JR"></a>

3. Click **OK** to confirm that you want to delete the option set.
