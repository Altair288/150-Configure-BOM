To access the information page of an option set, go to the **Option Sets** table, locate the option set you want to view, and click ![](../../../../../../images/d371d2ffb4ed_IconInfoPage.gif).

## Actions

<a id="wwID0EHILR"></a>

Information pages contain a list of applicable actions in a menu just below the object identification line. See [Common Actions](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/commonactions/CommonActionsRef.html) for a list of common actions available in Windchill. The availability of these actions depends on the status of the option set, as well as your access to it.

## Tabs

<a id="wwID0EPPLR"></a>

The following tabs are available on the option set information page. You can customize the tabs that appear on each object information page to display the information most useful to you. For more information, see [Customizing Information Page Tabs](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/objectoview/ObjectOviewInfoPageCustomize.html).

> ![\*](../../../../../../images/6652ad397dd1_note_16x16.png) **Note:** Administrators may have modified the tabs that are viewable to you.

| Tab | Description |
| --- | --- |
| **Details** | Information about the attributes of the option set. |
| **Structure** | The tree view of the option set with groups, options, and choices in the left pane of the page. Depending on the item selected in the left pane, you can select the following tabs in the right pane: **Attributes**, **Design Option**, **Sales Option**, **Include Rules**, **Exclude Rules**, **Enable Rules**, and **Where Used**. |
| **Changes** | Information on change tracking, including **Change Requests**, **Issues and Variances**, and so on. |

<a id="wwID0EGWLR"></a>

## Information on Variant Specifications

<a id="wwID0EKWLR"></a>

You can access information related to the variant specification and variant parts that are associated with this option set by adding a new tab, selecting Customize > Related Objects, and then selecting **Variant Specifications**. The following tables appear:

<a id="wwID0EWXLR"></a>

- **Variant Specifications** – Lists variant specifications that exist for this option set. From this table, you can delete a variant specification by clicking ![](../../../../../../images/22aa5ed232d8_IconDelete.gif).

<a id="wwID0ECZLR"></a>

- **Export** — Exports the list of variant specifications to any of the available formats such as CSV, HTML, PDF, XML.
