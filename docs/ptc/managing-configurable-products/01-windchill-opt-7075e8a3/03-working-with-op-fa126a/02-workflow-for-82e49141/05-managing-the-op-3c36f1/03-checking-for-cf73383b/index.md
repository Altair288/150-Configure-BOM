# Checking for Duplicate Choices

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsCheckiForDupChoices.html)  
> 获取日期：2026-11-12

<a id="wwID0ELPMR"></a>

<a id="wwID0E2PMR"></a>

You can check if the option set contains duplicate choices.

<a id="wwID0EYQMR"></a>

1. Go to the information page of the option set and click the **Structure** tab.

<a id="wwID0E5RMR"></a>

2. Click the toolbar action ![](../../../../../../images/752aff5f4494_Exp_IconVerifyTable.gif) in the left pane of the **Structure** page.

<a id="wwID0ELTMR"></a>

3. The **Duplicate Choices** window opens, listing duplicate choices found within the option set. For each duplicate choice, you can review the options that contain that choice.

<a id="wwID0ERUMR"></a>

4. Close the window to take a corrective action. For example, you may want to delete or rename the duplicate choice.
