# Editing an Option Set

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsSetEdit.html)  
> 获取日期：2026-11-12

<a id="wwID0EZPJR"></a>

<a id="wwID0ENQJR"></a>

An administrator can edit an option set to change its attributes. Editing an option set does not change the contents of the option set, only its characteristics.

> ![\*](../../../../../images/6652ad397dd1_note_16x16.png) **Note:** After the option set it created, you cannot change the setting for the **Manage Local Rule Changes Independently from the Option Set** attribute.

<a id="wwID0EQRJR"></a>

To edit an option set:

<a id="wwID0EZRJR"></a>

1. Go to the information page of the option set and click **Edit**.

<a id="wwID0E5SJR"></a>

2. The **Edit** window appears. Edit the attributes of the option set.

<a id="wwID0EEUJR"></a>

3. Click **OK**.

|  |  |
| --- | --- |
| **![\*](../../../../../images/887c9a51d571_tip_16x16.png)** | You can also edit the option set from the **Option Sets** table, by right-clicking the option set and selecting **Edit**. |
