# Exporting and Importing an Option Set

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsExport.html)  
> 获取日期：2026-11-12

<a id="wwID0E21SR"></a>

<a id="wwID0EP2SR"></a>

You can export an option set, so it can be later imported in another system. When exporting an option set, the system exports the choice rules included in the option set as follows:

<a id="wwID0EI3SR"></a>

- For the choice rules that were inherited from the option pool, the system exports latest iteration of the latest revision of the choice rules.

<a id="wwID0EK4SR"></a>

- For the choice rules that were selected for inclusion in the option set, the system exports the version of the rule that was added to the option set.

<a id="wwID0EL2SR-1"></a>

To export an option set:

<a id="wwID0ET5SR"></a>

1. Go to the information page of the option set.

<a id="wwID0EV6SR"></a>

2. Select **Export** from the **Actions** menu. The **Export** window opens.

<a id="wwID0EDBTR"></a>

3. Specify the name for the export file.

<a id="wwID0EFCTR"></a>

4. Click **Submit**.

<a id="wwID0E3CTR"></a>

To import an option set, go to Utilities > Import/Export Management, and click **Import**.
