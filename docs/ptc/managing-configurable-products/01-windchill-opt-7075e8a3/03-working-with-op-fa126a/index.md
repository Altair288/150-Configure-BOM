# Working with Option Sets

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsSetWork.html)  
> 获取日期：2026-11-12

<a id="wwID0ECFHR"></a>

<a id="wwID0ESFHR"></a>

To manage option sets, go to the information page of the part, product, or library, and show the **Option Sets** table by adding a new tab and selecting Customize > General > Option Sets.

<a id="wwID0ESGHR"></a>

The **Option Sets** table has the following actions on the toolbar:

<a id="wwID0EPHHR"></a>

- ![](../../../images/bf930923297f_IconCopy.gif) – Copy an option set to a clipboard.

<a id="wwID0EXIHR"></a>

- ![](../../../images/22aa5ed232d8_IconDelete.gif) – Delete an option set.

<a id="wwID0E6JHR"></a>

- ![](../../../images/5b29911fa22e_IconOptionSetNew.png) – Create a new option set.

<a id="wwID0EHLHR"></a>

- ![](../../../images/40705772a75f_IconAddTo.gif) – Add an option set to a package.

<a id="wwID0EAMHR"></a>

You can perform a number of actions by right-clicking an option set in the **Option Sets** table. The following actions may be of particular interest to you.

| Action | Description |
| --- | --- |
| **Save As** | Save the option set to a different name in a selected context, and modify its attributes, if needed. |
| **Edit** | Edit the option set. |
| **Rename** | Rename the option set. |
| **Subscribe** | Subscribe to events associated with the option set. |

<a id="wwID0E3RHR"></a>

To work with a specific option set, locate it in the **Option Sets** table and click ![](../../../images/d371d2ffb4ed_IconInfoPage.gif). This takes you to the information page of the option set. Click the **Structure** tab to view and manage the options and choices included in the option set. For more information on managing options in the option set, go to [Managing the Option Set](02-workflow-for-82e49141/05-managing-the-op-3c36f1/index.md#wwID0EZ3JR "Managing the Option Set").
