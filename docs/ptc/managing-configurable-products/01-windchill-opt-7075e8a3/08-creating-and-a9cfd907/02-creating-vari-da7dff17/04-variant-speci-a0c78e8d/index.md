# Variant Specification Step: Defining a Variant Specification

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsVarSpeciDefine.html)  
> 获取日期：2026-11-12

<a id="wwID0EQOQS"></a>

<a id="wwID0EAPQS"></a>

A variant specification is a collection of inputs and selections specified for a configurable structure in preparation for creating a variant. To create a variant specification, you configure a configurable module or a configurable product using the **Configure** action.

<a id="wwID0ELPQS"></a>

In the Variant Specification step of the configuration process, you specify the name and description for the variant specification.

<a id="wwID0EQPQS"></a>

After you have completed the definition of the variant specification, you can either save it and then click **Finish** to end the configuration process, or you can click **Next** to request deliverables.
