# Creating a Copy of the Variant Specification

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsVarSpecSaveAs.html)  
> 获取日期：2026-11-12

<a id="wwID0EWPTS"></a>

<a id="wwID0EGQTS"></a>

To create a copy of the variant specification, use **Save As**.

<a id="wwID0EIRTS"></a>

1. Go to the information page of the variant specification.

<a id="wwID0EKSTS"></a>

2. From the **Actions** menu, select **Save As**. The **Save As** window opens.

<a id="wwID0EYTTS"></a>

3. Enter a number, name, and description, and then select the location for the new variant specification.

<a id="wwID0E2UTS"></a>

4. Click **OK**.
