# Loading Variant Specifications

<a id="wwID0EKMTS"></a>

Companies can load variant specifications in Windchill to create new and update existing variant specifications using a command-line utility that can be run from a Windchill shell using a formatted spreadsheet as input. For more information, see [Loading Variant Specifications from a Spreadsheet](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/WCDataLoadGuide/WCDataLoad_OptionsLoadVarSpecSpreadsheet.html).
