# Revision and Change Management for Variant Specifications

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsChangeManageVarSpec.html)  
> 获取日期：2026-11-12

<a id="wwID0E1MSS"></a>

<a id="wwID0EKNSS"></a>

A variant specification is a revision- and change-controlled item. You can create a Problem Report, a Change Request, or a Change Notice for a Variant Specification from the information page of the variant specification or from the **Folder Contents** table.

<a id="wwID0EUNSS"></a>

The revision control and change management behavior for variant specifications is the same as for parts and documents.
