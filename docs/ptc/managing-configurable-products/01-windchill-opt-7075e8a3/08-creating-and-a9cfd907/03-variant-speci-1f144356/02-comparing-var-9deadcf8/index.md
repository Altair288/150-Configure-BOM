# Comparing Variant Specifications

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/ExpComparisonOptions.html)  
> 获取日期：2026-11-12

<a id="wwID0E1FSS"></a>

<a id="wwID0EOGSS"></a>

You can compare the values of two or more variant specifications.

<a id="wwID0ESGSS"></a>

To compare variant specifications and multiple iterations of the same variant specification:

<a id="wwID0ELHSS"></a>

1. Go to the information page of the variant specification. From the **Actions** menu, choose **Compare Information**. The **Find Object** window appears.

<a id="wwID0EJISS"></a>

2. Enter any desired search criteria and then click **Search**. If you leave the fields blank, it will search for all available variant specifications. The results are displayed in the **Search** table.

<a id="wwID0ECJSS"></a>

3. From the **Search** table, select the variant specifications you want to compare.

<a id="wwID0EHKSS"></a>

4. Click **OK**. The **Comparison Options** window appears.

<a id="wwID0EBLSS"></a>

5. Select the checkboxes to indicate what you want to display in the comparison report.

<a id="wwID0ESLSS"></a>

6. Click **OK** to generate the report.
