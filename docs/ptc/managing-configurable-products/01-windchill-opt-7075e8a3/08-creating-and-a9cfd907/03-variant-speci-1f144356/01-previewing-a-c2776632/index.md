# Previewing a Variant Specification

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsVarSpecPreview.html)  
> 获取日期：2026-11-12

<a id="wwID0E56RS"></a>

<a id="wwID0EOASS"></a>

You can preview a variant specification using the **Preview** action from the following locations:

<a id="wwID0ELBSS"></a>

- From the actions menu on the information page of the variant specification

<a id="wwID0ENCSS"></a>

- From the **Variant Specification** table associated with a configurable product

<a id="wwID0ETDSS"></a>

- From the search results table for the variant specifications

<a id="wwID0EVESS"></a>

- From the folder browser containing the variant specifications
