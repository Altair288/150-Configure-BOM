# Managing Deliverables

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsCompDeliverables.html)  
> 获取日期：2026-11-12

<a id="wwID0EEWTS"></a>

<a id="wwID0EUWTS"></a>

In addition to the variant module, you can attach other objects to the variant specification, for example a document or a CAD model.

<a id="wwID0EZWTS"></a>

You can view and manage completed deliverables from the information page of the variant specification.

<a id="wwID0ESXTS"></a>

1. On the information page of the variant specification, add a new tab, and select Customize > Related Objects > Deliverables. The **Completed Deliverables** and **Requested Deliverables** tables appear.

<a id="wwID0ESZTS"></a>

2. Use the**Completed Deliverables** table to manage deliverables. You can perform the following actions:

<a id="wwID0E21TS"></a>

- Add a deliverable by clicking ![](../../../../images/c7468099aab3_IconDeliverableAdd.gif).

<a id="wwID0EE3TS"></a>

- Remove a deliverable by clicking ![](../../../../images/719458d18c9a_IconDeliverableRemove.gif).

<a id="wwID0EN4TS"></a>

- Export the deliverables to a file that can be accessed offline in programs such as Microsoft Excel.

<a id="wwID0EP5TS"></a>

- Right-click a deliverable to access other actions.
