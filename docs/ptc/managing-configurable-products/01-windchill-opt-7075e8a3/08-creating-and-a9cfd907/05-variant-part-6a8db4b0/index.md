# Variant Part Information Page

> 来源：PTC Windchill Help Center（R13.1.2.0）  
> 原文：[PTC Help Center](https://support.ptc.com/help/windchill/r13.1.2.0/en/Windchill_Help_Center/options/OptionsVariantPartInfoPage.html)  
> 获取日期：2026-11-12

<a id="wwID0EW6TS"></a>

<a id="wwID0EHAUS"></a>

You can view information on the configurable modules, variant specifications, and variant baselines that are associated with the selected module variant. To access this information, go to the module variant information page, add a new tab, and then customize the view by selecting Customize > Related Objects. From the **Related Objects** list, you can choose the following objects:

<a id="wwID0EVBUS"></a>

- **Configurable Modules**— Shows the configurable modules to which the part is associated as a variant. You can perform the following actions from this table:

<a id="wwID0E4CUS"></a>

- Remove this module variant so it is no longer associated as a variant to a selected configurable module. Select a configurable module and click ![](../../../../images/ae4a236e741a_IconRemove.gif).

<a id="wwID0EHEUS"></a>

- Verify if the relationship between the selected configurable module and the module variant is still valid. Select a configurable module and click ![](../../../../images/51dde020d5f6_IconPartVerify.gif). The system reports validation results. If the relationship is no longer valid, it removes the configurable module from the table.

<a id="wwID0EQFUS"></a>

- Export the configurable modules to a file that can be accessed offline in programs such as Microsoft Excel.

<a id="wwID0ETGUS"></a>

- **Variant Specifications**—Shows the **Variant Specifications for this Module Variant** table that lists the variant specifications that exist for this module variant. From this table, you can:

<a id="wwID0E6HUS"></a>

- Compare information between two variant specifications. Select two variant specifications and click ![](../../../../images/cf4877739b1e_IconCompare.gif).

<a id="wwID0EIJUS"></a>

- Compare variant solutions – Select two variant specifications and click ![](../../../../images/bf284e697167_IconVariantSolutionCompare.gif).

<a id="wwID0ERKUS"></a>

- Delete the variant specification associated with this module variant. Select a variant specification and click ![](../../../../images/22aa5ed232d8_IconDelete.gif).

<a id="wwID0E1LUS"></a>

- Export the variant specifications to a file that can be accessed offline in programs such as Microsoft Excel.

<a id="wwID0E4MUS"></a>

- **Variant Baselines**— Shows the **Variant Baselines** table that lists the variant baselines available for this module variant. You can perform the following actions from this table:

<a id="wwID0EJOUS"></a>

- Open the variant baseline in a product family matrix editor —Select a variant baseline and click ![](../../../../images/3b4b9523ee4f_IconOpenInProductFamilyMatrixEditor.gif).

<a id="wwID0ESPUS"></a>

- Edit baseline members —Select a variant baseline and click ![](../../../../images/30f7a36c47f2_IconEditBaselineMembers.gif).

<a id="wwID0E2QUS"></a>

- Update baseline objects — Select a variant baseline and click ![](../../../../images/7b29a48a9e04_IconUpdateBaselineObjects.gif).

<a id="wwID0EESUS"></a>

- Create new change notice — Select a variant baseline and click ![](../../../../images/17e3e2513376_IconNewChangeNotice.gif).
